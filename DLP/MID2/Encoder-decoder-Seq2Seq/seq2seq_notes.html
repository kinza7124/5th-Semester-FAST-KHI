Encoder — Input Processing

What the Encoder Does

The encoder reads the input sentence and compresses it into a latent representation.

Idea

  • Converts high-dimensional sequence → low-dimensional vector (latent space)
  • This vector contains the meaning of the whole sentence

Step-by-Step Processing

For an Urdu sentence: "میں سکول جاتا ہوں", the encoder processes each word step by step:

W1 → W2 → W3 → W4

Final output = Latent Vector Context

03

Latent Space (Context Vector)

Fixed-Length Vector

A fixed-size numerical representation of the entire input sentence.

Semantic Meaning

Contains semantic meaning (not just words) — it's the "memory" passed to the decoder.

Summary Role

Acts as a summary of the entire input sentence for the decoder to start generating.

Key Insight: The context vector is the bottleneck — it must compress all the information of the input. This is both the strength and the limitation of basic encoder-decoder.

Teacher Forcing

Definition: The key difference between training and testing in sequence generation.

🎓 Training Phase (Teacher Forcing)

Instead of using the predicted output as the next input, we use the actual correct word.

Example

  • True output: "I go to school"
  • Model predicted: "I am to school"
  • Next input = correct word "go", NOT "am"

Why?

  • Makes training faster
  • Stabilizes learning
  • Prevents error accumulation

🧪 Testing Phase

No ground truth available.

  • Model uses its own predictions
  • Each predicted word becomes the next input
  • Errors can accumulate (exposure bias problem)
Train: input = y_true[t-1]
Test: input = ŷ[t-1] (predicted)

Why Encoder-Decoder Works + Limitations

✅ Why It Works

  • Handles variable-length input & output
  • Learns sequence-to-sequence mapping
  • Captures meaning of full sentence
  • Architecture: Input → Encoder → Latent Vector → Decoder → Output

⚠️ Limitations

  • Fixed latent vector = information bottleneck
  • Long sentences = loss of information
  • Early encoder states forgotten by the end
Solution → Attention Mechanism

Dataset Setup

For English→Urdu translation, the dataset contains paired sentences:

Words are converted to one-hot vectors via NLP tokenization. Example with vocabulary ["think", "about", "it", "come", "in"]:

لو → [0,0,1,0,0,0,0]

<end> → [0,0,0,0,0,0,1]

Weights are initialized randomly at the start of training.

Softmax Layer & Loss Function

Softmax Layer

# of nodes = # of words in vocabulary

Softmax generates a probability for every word in the vocabulary. The word with the highest probability is predicted.

y_pred = [0.2, 0.1, 0.3, 0.2, 0.1, 0.1]
// highest → 0.3 → predicted word

Loss Function

Categorical Cross-Entropy:

L = -Σ yᵢᵗʳᵘᵉ · log(yᵢᵖʳᵉᵈ)

Example Calculation

L₍t=1₎ = -1 × log(0.1) = 1
L₍t=2₎ = 1
L₍t=3₎ = -1 × log(0.4) = 0.39
L_total = 2.39

Backpropagation Steps

  • ① Calculate gradient of loss w.r.t. weights
  • ② Update parameters using gradient
  • Learning rate controls step size
  • Optimizer: typically Adam

Forward vs Backward

Forward: input → output → loss
Backward: loss → gradient → ∂W
Update: W_new = W - lr · ∂W

During testing — no teacher forcing, model uses its own predictions.

Improvements to Encoder-Decoder

Improvement 1 — Embeddings

Instead of one-hot encoding, use an Embedding Layer before the LSTM:

  • Captures semantic meaning of words
  • Provides low-dimensional dense representation
  • Can use pretrained embeddings: Word2Vec GloVe
Figure 9 — Embedding layers feed into encoder and decoder LSTM chains

Improvement 2 — Deep LSTM

Stack multiple LSTM layers (instead of one). Each layer captures increasingly abstract representations:

word → sentence → paragraph
Advantage 1

Long-term dependency: Every LSTM layer captures long-term dependencies → good for large paragraphs.

Advantage 2

Layered representation: Better understands hierarchical structure of language.

Advantage 3

Deep learning: Learns patterns well, better generalization.

Improvement 3 — Reversing the Input

Reverse the input sequence before feeding to the encoder:

"Think about it" → reversed → "it about Think"
  • Works for some language pairs only
  • Useful when initial words of source align with initial words of target
  • Works for languages where the first word holds more context (e.g., English)

Attention Mechanism

The Problem Solved: For translation of any word, only some words matter — not the whole long paragraph. Encoder-Decoder compresses everything into one context vector. Attention lets the decoder focus on relevant encoder states at each decoding step.

Core Idea

Instead of a single fixed context vector, attention computes a dynamic context vector for each decoder timestep as a weighted sum of all encoder hidden states:

ci = Σⱼ αij · hj

Where:

  • h_j = encoder hidden state at step j
  • α_ij = attention weight (how much decoder step i attends to encoder step j)
  • c_i = context vector for decoder step i

The α weights differ at every decoder timestep.

Figure 10 — Attention mechanism: weighted sum over encoder states gives dynamic context

Notation

  • i = decoder timestep
  • j = encoder timestep
  • α_ij = how much decoder step i attends to encoder step j
  • Total α: i × j = 4×4 = 16 attention weights (for 4-word inputs/outputs)
c_i = Σⱼ α_ij · h_j    // context for decoder step i
c₂ = α₂₁h₁ + α₂₂h₂ + α₂₃h₃ + α₂₄h₄
14

Bahdanau (Additive) Attention

How α is Calculated (Bahdanau)

The alignment score is computed using a Feed-Forward Neural Network (ANN):

e_ij = f(h_j, s_{i-1})    // ANN(encoder hidden, prev decoder hidden)
α_ij = exp(e_ij) / Σₖ exp(e_ik)    // Softmax normalization
c_i = Σⱼ α_ij · h_j    // weighted sum = context vector

Note: The ANN weights are shared across all timesteps.

Bahdanau Architecture

  • α_ij = f(h_j, s_{i-1}) — uses previous decoder state
  • Additive attention (concatenation + tanh)
  • Uses biLSTM in encoder for both directions
  • More dynamic adjustment capability
c_i* = tanh(W[s_{i-1} · h_j] + b)

Key Inputs to Alignment Model

  • h_j: encoder hidden state at timestep j (output from encoder)
  • s_{i-1}: hidden state of previous decoder block
  • These two vectors are fed into the ANN
  • ANN acts as a universal function approximator
Figure 11 — Bahdanau attention: ANN computes alignment scores from encoder states and previous decoder state
15

Luong (Multiplicative) Attention

Key Difference from Bahdanau

Luong attention uses the current decoder state (not previous) and computes alignment via dot product:

α_ij = f(s_i, h_j)    // current decoder state
e_ij = s_iᵀ · h_j    // dot product (simpler)

Dot Product Computation

If s_i = [a,b,c,d] and h_j = [e,f,g,h]:

sᵀ · h = ae + bf + cg + dh
// single scalar score

Then normalize with Softmax → α weights.

Concatenate Variant

Some variants concatenate s_i and h_j before the dense layer:

s_i:h_j → s̃ → softmax
// Feed-Forward Dense Layer
Feature Bahdanau Luong
Decoder state used s_{i-1} (previous) s_i (current)
Score function ANN / tanh (additive) Dot product (multiplicative)
Complexity Higher (ANN weights) Lower (just dot product)
Flexibility More dynamic Simpler & faster
Context placement Before decoder step After decoder step
