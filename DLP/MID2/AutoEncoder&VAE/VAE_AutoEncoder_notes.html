0 Beginner Vocabulary

Why this section?

Generative model papers throw around words like stochastic, latent space, and prior without explaining them. This glossary gives you plain-English definitions before diving in.

Deterministic
Given the same input, you always get the exact same output. No randomness involved. Like a calculator — 2+2 is always 4.
→ Regular Autoencoder: same image always gives same z.
Stochastic
Involves randomness. The same input may produce slightly different outputs each time because a random sample is drawn.
→ VAE encoder: same image gives a different sampled z each time.
Latent Space
A compressed, hidden (latent = hidden) representation of data. Think of it as a map where similar things are stored near each other in a smaller number of dimensions.
→ A face image (128×128 pixels) compressed to a vector of just 32 numbers.
Latent Variable (z)
The compressed code that lives in latent space. It captures the essence of the input — the most important features — in a compact form.
→ z might encode: "smiling, young, glasses" for a face.
Distribution
A mathematical description of how likely different values are. Instead of storing one number, you store a shape (like a bell curve) that tells you the probability of every possible value.
→ Instead of z=3.5, VAE stores "z is likely around 3 ± 0.5".
Gaussian / Normal Distribution
The classic bell curve. Defined by mean μ (center) and variance σ² (width). Written as N(μ, σ²). When μ=0, σ=1, it's called the standard normal N(0,1).
→ VAE forces latent distributions to stay close to N(0,1).
μ (Mu) — Mean
The average / center of a distribution. Tells you "where" the bell curve is located on the number line.
→ μ=0 means the distribution is centered at zero.
σ (Sigma) — Std. Deviation
How spread out a distribution is. Small σ = narrow spike. Large σ = wide bell. σ² is called variance.
→ σ=1 means a "normal" spread around the mean.
Encoder
The "compressor" part of an autoencoder. Takes high-dimensional input and maps it to a small latent code z.
→ Input image (50,000 values) → encoder → z (32 values).
Decoder
The "decompressor". Takes the latent code z and reconstructs the original input as closely as possible.
→ z (32 values) → decoder → reconstructed image (50,000 values).
Prior p(z)
What we assume the latent space should look like before seeing any data. In VAEs this is always N(0,1) — a simple standard Gaussian.
→ "Before training, we expect z to look like a standard normal bell."
Posterior q(z|x)
The learned distribution of z given a specific input x. This is what the encoder actually outputs — the "after we see x" distribution.
→ Given face image x, encoder outputs q(z|x) = N(μ(x), σ²(x)).
KL Divergence
A number measuring how different two distributions are. KL=0 means identical. Higher = more different. Used in VAE to penalize the encoder if its distribution drifts too far from N(0,1).
→ KL(q||p) = 0 when q is exactly N(0,1).
Reconstruction Loss
How different the output is from the input. Measures how well the decoder rebuilds what the encoder compressed. Usually mean squared error (MSE).
→ ℒ = ‖x − x̂‖² — sum of squared pixel differences.
Reparameterization
A trick to make random sampling differentiable. Instead of sampling z directly (blocking gradients), we write z = μ + σ·ε where ε is random noise drawn externally.
→ Lets backpropagation work through the stochastic layer.
Backpropagation
How neural networks learn. Gradients of the loss are computed and sent backward through the network to update weights. Requires all operations to be differentiable.
→ Random sampling breaks backprop — hence the reparam trick.
ELBO
Evidence Lower BOund. The VAE loss written from a probability theory view. Maximizing ELBO = minimizing reconstruction loss + KL divergence. It's a lower bound on log p(x).
→ L_ELBO = E[log P(x|z)] − KL(q(z|x) ‖ p(z)).
Disentanglement
When each dimension of z controls exactly one meaningful, independent feature. "Disentangled" means the factors are separated — changing z₁ changes only "smile", changing z₂ changes only "age".
→ β-VAE promotes disentanglement by increasing KL weight.
Sampling
Drawing a random value from a distribution. Like rolling a dice — you pick a value according to the probabilities the distribution specifies.
→ VAE samples z ~ N(μ, σ²) to introduce controlled randomness.
Bottleneck
The narrowest, most compressed layer in an autoencoder — where z lives. It forces the network to squeeze information through a small channel, preventing lazy copying.
→ Input: 784 dims → hidden: 256 → bottleneck z: 32 dims.
Quick mental model: Think of a VAE like a very smart zip file. The encoder creates the zip (latent z). The decoder unzips it. But unlike a regular zip, the VAE learns a distribution for the zip — so you can create new valid zips from scratch and unzip them into brand new, realistic data.
1 Autoencoders

What is an Autoencoder?

An Autoencoder is an unsupervised neural network that learns to compress (encode) input data into a low-dimensional latent space z, then reconstruct (decode) it back. Since there are no labels, it uses the input itself as the target — self-supervised learning.

Fig 1: Autoencoder — Encoder compresses x→z, Decoder reconstructs z→x̂. Loss = MSE between input and output.

Encoder

Maps input x → z (latent space). A series of NN layers that progressively compress the data. Traditional AEs are deterministic — one fixed vector z per input.

Decoder

Maps latent z → x̂. Expands back to original dimensionality. Trained to minimize reconstruction loss: ℓ = ‖x − x̂‖²

Loss Function — RMSE/MSE

ℓ(x, x̂) = ‖x − x̂‖² For images: pixel-wise squared difference = Σ (original_pixel − reconstructed_pixel)²

The loss does not use any labels — the input is its own target. This is what makes it unsupervised.

Why a Bottleneck?

  • Forces compression: network must learn what's truly important
  • Learns compact representations: latent z = essence of the input
  • Without bottleneck: network could simply memorize/copy inputs
  • Trade-off: smaller z → harder to reconstruct → higher loss
Limitation: Traditional autoencoders are deterministic. z is a single fixed point per input — you cannot sample new, meaningful data from the latent space. That's why VAEs exist.
2 Variational Autoencoders (VAE)

Core Idea

Instead of encoding x to a single point z, a VAE encodes it to a probability distribution — specifically N(μ, σ²). We then sample z from this distribution to pass to the decoder. This makes the latent space smooth and continuous, enabling generation of new data.

Fig 2a: VAE Architecture — Probabilistic encoder outputs μ and σ, latent z is sampled via reparameterization, decoder reconstructs x̂. Loss = ELBO = Reconstruction − KL.
Fig 2b: VAE as Neural Network — Left (Inference/Encode) path learns qφ(z|x); Right (Generative/Decode) path learns pθ(x|z). The bottleneck outputs μ and σ of the latent distribution.
Fig 2c: VAE Detail — Probabilistic Encoder qφ(z|x) outputs mean μ and std. dev σ. Sampled latent vector z = μ + σ⊙ε (reparameterization). Probabilistic Decoder pθ(x|z) reconstructs x′.
Fig 2d (SVG): VAE Architecture — Encoder outputs μ and σ², reparameterization trick computes z = μ + σ·ε, Decoder reconstructs x̂.

vs Regular AE — Key Difference

  • AE: z = single fixed vector (deterministic)
  • VAE: z ~ N(μ, σ²) (probabilistic / stochastic)
  • VAE learns a distribution, not a point
  • VAE can generate new samples by sampling z

Properties of Latent Space

  • Continuity: nearby z → similar decoded output
  • Completeness: any sampled z → meaningful output
  • Without regularization: these properties break!

VAE Loss Function

ℓ(φ, θ, x) = Reconstruction Loss + Regularization Term = E_q[log p_θ(x|z)] − D_KL(q_φ(z|x) ‖ p(z)) ↑ ↑ How well decoder How close q(z|x) is reconstructs x to prior N(0,1)

Both terms must be minimized simultaneously. There is a trade-off: more regularization → smoother latent space but possibly lower reconstruction quality.

Reparameterization Trick — Why We Need It

Sampling z ~ N(μ, σ²) is non-differentiable (stochastic) — gradients cannot flow through a random sampling operation. Backprop requires deterministic behavior.

❌ Original (non-differentiable / stochastic): z ~ q_φ(z|x) = N(μ, σ²) ✅ Reparameterized (differentiable / deterministic): z = μ + σ · ε, where ε ~ N(0, 1) ε is constant (external noise — stochastic part is isolated here) μ and σ are now the differentiable variables

This moves randomness into ε (which is sampled from a fixed distribution) while keeping μ and σ differentiable — so gradients can flow back through the network.

Fig 3a: Reparameterization Trick — Left: z is a random node (stochastic) — gradients cannot pass through. Right: after reparameterization, z = μ + σ⊙ε is a deterministic node — gradients flow through μ and σ normally. ε ~ N(0,1) is external randomness.
Fig 3b (SVG): Reparameterization — Left: stochastic Z blocks backprop. Right: ε is external constant, gradients flow through deterministic Z = g(φ, x, ε).
Example: μ = 2, σ = 3, ε = 0.5 → z = 2 + 3 × 0.5 = 3.5. The randomness came from ε (fixed), so μ and σ remain differentiable.
3 KL Divergence

Definition

KL Divergence measures how different one probability distribution is from another. In VAEs, it measures the gap between the learned latent distribution q_φ(z|x) and the standard normal prior p(z) = N(0,1).

Fig 4a: KL Divergence for VAEs — Formula and explanation of each term. The goal: make learned qφ(z|x) as close as possible to standard normal p(z) = N(0,1).
D_KL(q_φ(z|x) ‖ p(z)) = −½ Σⱼ₌₁ᵏ (1 + log σ²ⱼ − μ²ⱼ − σ²ⱼ) Each term explained: log σ²ⱼ → prevents variance collapsing to 0 (log 0 = -∞ → huge penalty) −μ²ⱼ → penalizes mean moving away from 0 −σ²ⱼ → penalizes very large variance +1 → balancing constant from Gaussian formula −½ → scaling factor for correct magnitude
Fig 4b: KL Divergence — measures gap between learned q_φ(z|x) and prior N(0,1). KL=0 when they perfectly overlap.

Role as Regularizer

  • Acts as a soft constraint on latent space
  • Pushes μ toward 0
  • Pushes σ² toward 1
  • Prevents encoder from "cheating" by memorizing
  • Ensures smooth, useful latent space

Without Regularization

  • Variance may collapse to zero (deterministic/pointed distribution)
  • Means could diverge wildly from each other
  • Latent space loses continuity
  • Random sampling yields meaningless output

β-VAE Extension

ℓ(θ, φ; x, z, β) = E_q[log p_θ(x|z)] − β · D_KL(q_φ(z|x) ‖ p(z)) β > 1 → stronger regularization → more disentangled latent space β = 1 → standard VAE

Increasing β constrains the latent bottleneck, encouraging disentanglement — different dimensions of z encode independent interpretable features (e.g., smile, skin tone, age).

Fig 5: Latent space without vs. with KL regularization. KL forces distributions to overlap, enabling smooth interpolation.
Numerical example: If μ=0, σ²=1 → each term: log(1)=0, μ²=0, σ²=1 → KL = −½(1 + 0 − 0 − 1) = 0. Perfect! If μ=3, σ²=0.01 → KL becomes large, penalizing this distribution.
4 VAE Loss & Latent Perturbation

Full VAE Loss Breakdown

ℓ(φ, θ, x) = Reconstruction Loss + Regularization Reconstruction = E_q_φ[log p_θ(x|z)] → for images: MSE = ‖x − x̂‖² → measures how faithfully decoder reconstructs x Regularization = D_KL(q_φ(z|x) ‖ p(z)) → = −½ Σ (1 + log σ²ⱼ − μ²ⱼ − σ²ⱼ) → keeps latent space near N(0,1)
Trade-off: Regularize too much → blurry reconstructions. Regularize too little → discontinuous latent space, can't generate new data. β-VAE balances this with the β hyperparameter.

Reconstruction Term

E_q_φ[log p_θ(x|z)]

  • Measures decoder's accuracy
  • For images: MSE between x and x̂
  • Higher = decoder is doing well
  • This term we want to maximize

KL Regularization Term

D_KL(q_φ(z|x) ‖ p(z))

  • Measures how stochastic/spread the latent is
  • Pushes distribution toward N(0,1)
  • Lower = more similar to prior
  • This term we want to minimize

Latent Space Perturbation (Interpretation)

Once a VAE is trained, you can manually change dimensions of z to understand what each dimension controls. This is called latent perturbation.

Example (face generation): z = [0.1, -0.3, 0.8, ...] Change z[0] from 0.1 → 2.0 → person starts smiling Change z[2] from 0.8 → -1.0 → face rotates left Change z[5] from 0.0 → 1.5 → person ages

A well-regularized VAE has a smooth latent space — interpolating between two z vectors generates meaningful transitions between data points.

5 Seq2Seq vs Autoencoder

Seq2Seq (Sequence-to-Sequence)

Seq2Seq is an encoder–decoder architecture designed for sequence transformation tasks (e.g., translation, summarization). The encoder compresses the input sequence into a context vector; the decoder generates a different output sequence — not necessarily the same as input.

Fig 6: Seq2Seq transforms one sequence into another (different). AE reconstructs the same input.

Key confusion: Both AE and Seq2Seq have encoder–decoder architectures, but their purposes are completely different. AE learns a compressed representation of the same data. Seq2Seq learns to map one domain/language to another.
6 Exam Q&A
🎓 Autoencoder Questions
Q1: What is an Autoencoder and how is it trained? ▼

An Autoencoder is an unsupervised neural network with an encoder and decoder. The encoder compresses input x to a low-dimensional latent vector z; the decoder reconstructs x̂ from z. Training uses reconstruction loss ℓ = ‖x − x̂‖² (no labels). The bottleneck layer forces the network to learn a compressed, meaningful representation.

Q2: Why do we need a bottleneck in an Autoencoder? ▼

Without a bottleneck, the network could simply learn to copy the input (identity function), learning nothing useful. The bottleneck forces the network to learn a compact, meaningful representation — discarding noise and redundancies. Smaller bottleneck → harder compression → higher loss but more powerful feature learning.

Q3: Why can't we generate new data from a regular Autoencoder? ▼

Because the latent space z is deterministic. Each input maps to a single fixed point in latent space. There is no guarantee that points between those known locations decode into meaningful data — the latent space has no structure enforced on it. Random sampling from it gives garbage output.

🎓 VAE Questions
Q4: What is the key difference between an AE and a VAE? ▼

In AE: encoder outputs a single fixed vector z (deterministic). In VAE: encoder outputs a mean μ and variance σ², and z is sampled from N(μ, σ²) (stochastic). This probabilistic encoding, combined with KL divergence regularization, creates a smooth continuous latent space from which new data can be generated.

AE: z = encoder(x) [fixed point — deterministic] VAE: z ~ N(μ(x), σ²(x)) [sample from distribution — stochastic]
Q5: What is the Reparameterization Trick and why is it needed? ▼

Backpropagation requires deterministic, differentiable operations. Sampling z ~ N(μ, σ²) is stochastic (non-differentiable). The reparameterization trick reformulates:

z = μ + σ · ε where ε ~ N(0,1)

Now ε is an external constant (not a parameter), and μ, σ are the differentiable learned parameters. Gradients can flow through μ and σ normally. Example: μ=2, σ=3, ε=0.5 → z = 2 + 3(0.5) = 3.5

Q6: What are the two properties expected from VAE regularization? ▼

1. Continuity: Points that are close in latent space should produce similar reconstructions after decoding. If you move slightly in z space, the output should change smoothly.

2. Completeness: Any point sampled from the latent space should decode into meaningful content — no "holes" in the latent space that produce garbage.

Q7: What happens if we don't regularize the VAE? ▼

Without regularization, the model optimizes only reconstruction loss. This leads to:

  • Variance collapse: σ² → very small (pointed/delta distribution). The "distribution" degenerates into a single deterministic point like a regular AE.
  • Divergent means: μ values for different inputs could be far apart in latent space, creating discontinuities.
  • Randomly sampled z won't produce meaningful output.
🎓 KL Divergence Questions
Q8: Write and explain the KL Divergence formula for VAEs. ▼
D_KL = −½ Σⱼ (1 + log σ²ⱼ − μ²ⱼ − σ²ⱼ)
  • log σ²ⱼ: prevents variance from collapsing to zero
  • −μ²ⱼ: penalizes mean deviating from 0
  • −σ²ⱼ: penalizes variance becoming too large
  • +1: balancing constant from Gaussian formula
  • −½: correct scaling factor

Check: At μ=0, σ²=1: KL = −½(1 + 0 − 0 − 1) = 0 ✓

Q9: What is β-VAE and what does increasing β do? ▼
ℓ = Reconstruction − β · D_KL

β controls the strength of regularization. β > 1 applies stronger regularization to the KL term, which constrains the latent bottleneck more aggressively. This encourages disentanglement — each dimension of z encodes an independent, interpretable latent factor. Trade-off: β too large → reconstruction quality drops.

🎓 Seq2Seq Questions
Q10: How is Seq2Seq different from an Autoencoder? ▼

Autoencoder: Encoder–decoder trained to reconstruct the same input. No labels needed. Goal: learn compressed representation. Input = Output domain.

Seq2Seq: Encoder–decoder trained to transform one sequence to a different sequence. Requires parallel supervision (e.g., EN–FR sentence pairs). Goal: sequence transformation. Input ≠ Output domain.

Both use encoder–decoder architectures, but their objectives, losses, and supervision requirements are entirely different.

Q11: What are the 5 key capabilities of VAEs? ▼
  1. Compress representations of the world into something learnable
  2. Reconstruction allows for unsupervised learning (no labels needed)
  3. Reparameterization trick enables end-to-end training through stochastic sampling
  4. Interpret hidden latent variables using latent perturbation
  5. Generate new examples by sampling from the learned latent space

⚡ One-Line Recall

Autoencoder → compress and reconstruct, no labels, deterministic z

VAE → encode as distribution N(μ,σ²) (stochastic), reparameterize, regularize with KL, generate new data

KL Divergence → penalizes learned q(z|x) from drifting away from N(0,1), keeps latent smooth

Reparameterization → z = μ + σ·ε, isolates randomness in ε, makes μ & σ differentiable

Seq2Seq → transforms sequence A → sequence B (different domains), supervised
