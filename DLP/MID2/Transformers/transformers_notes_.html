1 Sequence to Sequence Networks

What is a Seq2Seq Network?

A Seq2Seq (sequence-to-sequence) network takes a series of input and generates a series-based output. It consists of an encoder (maps input → encoded representation) and a decoder (takes encoding → desired output).

One-to-Many

Fixed input → Variable output

Example: Image Captioning — CNN encodes image to feature vector, LSTMs decode to caption words.

Many-to-One

Variable input → Fixed output

Example: Sentiment Analysis — variable-length sentence → single sentiment label.

Many-to-Many

Variable input → Variable output

Example: Machine Translation — "le chat est noir" → "the cat is black".

Why Not Just Use RNN/LSTM?

RNN Problems

  • Slow training — sequential processing, cannot parallelize
  • Long sequences — gradients vanish or explode

LSTM Partial Fix

  • ✅ Solves vanishing/exploding gradients
  • ❌ Still sequential — still slow to train
  • ❌ Difficult to train on very long sequences
Motivation for Transformers: Both RNNs and LSTMs are sequential models — they process tokens one at a time. Transformers eliminate recurrence entirely, enabling full parallelization across all tokens in a sequence.
2 Transformer Architecture

Core Definition

A Transformer is a non-recurrent neural network. Unlike RNNs/LSTMs/GRUs which rely on recurrence, a Transformer processes all tokens in parallel. The original paper ("Attention is All You Need") stacks 6 encoder + 6 decoder units.

Fig 1: Full Transformer Architecture — Left: Encoder stack (N=6). Right: Decoder stack (N=6). Center: Encoder output feeds K,V into each decoder's Encoder-Decoder Attention block.
Key insight: Transformers replace recurrence with attention. Every token can directly attend to every other token in a single operation — no more sequential bottlenecks.
3 Encoder Block

Structure

The encoder consists of 6 identical units stacked (N=6 in the original paper). Each unit has 3 components:

1
Positional Encoding: Since Transformers are non-recurrent, they cannot naturally capture word order. Positional encoding adds position context to word embeddings. Input = Word Embedding + Positional Vector. Details in Section 6.
2
Multi-Head Self-Attention: Generates attention vectors (weights). Each word attends to all other words in the same input sequence. "Multi-head" means multiple sets of attention weights are computed in parallel, each capturing different relationships.
3
Feed Forward Network: A position-wise fully connected layer applied after attention. Transforms the attention vector into a form acceptable to the next encoder layer (or the decoder). Each position processed independently.

Add & Norm

After both the attention and FFN sub-layers, there is a residual connection followed by layer normalization.

Output = LayerNorm(x + Sublayer(x))

This helps prevent vanishing gradients and preserves information from earlier layers.

Output

The encoder stack outputs a contextualized representation of each input token — a matrix where each row encodes a word in context of all other words.

This output is passed to every decoder layer as the Key (K) and Value (V) matrices for encoder-decoder attention.

4 Decoder Block

Structure — 5 Components

The decoder also has 6 stacked units. Each unit has 5 components (2 more than the encoder):

1
Masked Multi-Head Self-Attention: Self-attention on the decoder's own output sequence (e.g., Urdu words generated so far). Masking ensures the decoder cannot "look ahead" — at position j, only words 1…j-1 are visible. Future tokens are hidden by setting their attention scores to -∞ (→ 0 after softmax).
2
Add & Norm (residual connection + layer normalization).
3
Encoder-Decoder Attention Block: Takes Queries (Q) from the previous decoder layer and Keys (K) + Values (V) from the encoder output. This is where the decoder learns to align with relevant parts of the input (source) sentence. Produces attention vectors capturing English-Urdu relationships.
4
Feed Forward Network: Makes the output vector more digestible for the next decoder layer or the linear layer.
5
Linear + Softmax Layer: Linear layer expands to vocabulary size (# unique words in corpus). Softmax converts to probability distribution. The word with the highest probability is selected as the next output token.
Why masking? During training, the decoder receives the full target sentence at once. Masking prevents it from "cheating" by seeing future words — it must predict the next word using only past context.
5 Training & Inference
Training Process

Setup

For English→Urdu translation: English sentence fed to encoder, Urdu sentence fed to decoder — but the decoder input is shifted right by one position.

1
Word Embeddings: Input words (e.g., "You are welcome") are converted to embedding vectors (e.g., word2vec). Positional encoding is added. Fed into the encoder stack.
2
Encoder stack (N=6): Processes all input tokens in parallel. Outputs contextualized representations (Enc-Out).
3
Decoder input: Target Urdu sentence fed with a <START> token prepended. The input is shifted right — at position j, only tokens 1…j-1 are available. Positional encoding added.
4
Decoder stack (N=6): Takes shifted Urdu tokens + encoder output. Masked self-attention prevents future peeking. Enc-Dec attention aligns with source.
5
Output probabilities: Linear layer expands to vocabulary size → Softmax → word probability distribution. Total output neurons = number of unique words in corpus.
6
Loss: Compare predicted words with actual target (Urdu sentence without shifting, with <EOS>). Backpropagate the loss.

Why Shift Right?

If the decoder input is not shifted, at position j the model sees the correct jth output and learns to simply copy it — trivially learning nothing. Shifting ensures: given encoder output + decoder tokens 1…j-1, predict token j.

Teacher Forcing

During training, even if the decoder predicts a wrong word, the correct word is still used as the next input. This is called teacher forcing — like a teacher providing hints. During inference, teacher forcing is off; the model uses its own (possibly wrong) previous predictions → may cause error accumulation.

Inference / Testing

Auto-regressive Generation

During inference, no ground-truth output is available. The decoder generates one token at a time, appending each prediction to the growing output sequence:

1
Feed encoder with the full input English sentence. Start decoder with <START> token → output first Urdu word.
2
Append the predicted first word to the decoder sequence.
3
Re-run decoder with <START> + word1 to predict word2.
4
Iterate — keep appending predicted tokens and re-running until <EOS> is generated or max length reached.
Key difference — training vs inference: Training feeds the actual target (shifted right) all at once. Inference feeds its own previous predictions one step at a time. This mismatch is called exposure bias.
6 Positional Encoding

Why Needed?

Transformers process all tokens in parallel — they have no inherent notion of order. The same word "dog" in "AJ's dog is a cutie" [pos 2] and "AJ looks like a dog" [pos 5] must produce different representations. Positional encoding injects position information by adding a unique vector to each word's embedding.

Final Input to Transformer = Word Embedding + Positional Encoding P(k, 2i) = sin(k / n^(2i/d)) ← even dimensions use SINE P(k, 2i + 1) = cos(k / n^(2i/d)) ← odd dimensions use COSINE Where: k = position of token in sequence (0 ≤ k < L) i = dimension index (0 ≤ i < d/2) d = embedding dimension n = 10,000 (user-defined scalar from original paper) L = length of sequence

Why Sine & Cosine?

  • Produces periodic patterns at different frequencies
  • Model can learn relative distances between positions
  • Continuous functions → generalizes to longer sequences than seen in training
  • Even indices → sine; Odd indices → cosine (alternating pattern)
  • Each position gets a unique vector combination

Key Properties

  • →Encodes absolute position (which position)
  • →Encodes relative position (how far apart)
  • →Same dimensionality as embeddings → can simply add
  • →No extra parameters — fixed, not learned

7 Scaled Dot-Product Attention

Self-Attention Definition

Self-attention allows each token in a sequence to directly attend to every other token. It asks: "For this word, which other words are most relevant?" The result is a context-aware representation where each word's meaning is influenced by its surrounding context.

The Q, K, V Framework

Query (Q)

The "question" a word asks of the sequence. "What information am I looking for?"

Analogy: The search query you type into a search engine.

Key (K)

The "index" of each word. Used to compute how relevant each word is to the query.

Analogy: The title/description of a webpage in search results.

Value (V)

The "content" of each word. The actual information returned once relevance is determined.

Analogy: The actual content of the webpage you clicked.

The Formula
Attention(Q, K, V) = softmax( QK^T / √dk ) · V Steps: 1. Compute QK^T → dot product of Query with all Keys (similarity scores) 2. Scale by 1/√dk → prevent large values from saturating softmax 3. Optional: Mask → set future positions to -∞ (decoder only) 4. Apply Softmax → convert scores to probability weights (sum to 1) 5. Multiply by V → weighted sum of Values = context-aware output Where: Q = Query matrix [seq_len × dk] K = Key matrix [seq_len × dk] V = Value matrix [seq_len × dv] dk = dimension of keys/queries

Why Divide by √dk?

Q and K are initialized as random variables with mean=0 and variance=1. Their dot product q·k has variance = dk (grows with dimension). Large values push softmax into regions with very small gradients (saturation). Dividing by √dk restores variance to 1 → stable gradients.

8 Multi-Head Attention

Limitation of Single-Head Attention

Single-head attention learns only one type of relationship at a time. But natural language has many simultaneous relationship types: syntactic (subject-verb), semantic (meaning), positional (nearby vs distant). One set of attention weights cannot capture all of these well.

How Multi-Head Works

Formula

head_i = Attention(Q·W_Q_i, K·W_K_i, V·W_V_i) ↑ each head has its OWN learned projection matrices MultiHead(Q, K, V) = Concat(head_1, head_2, ..., head_h) · W_O Where: h = number of heads (8 in original paper) W_Q_i, W_K_i, W_V_i = learned projection matrices for head i W_O = output projection matrix to combine heads

Head Specialization

  • Head 1 → grammatical structure (subject-verb)
  • Head 2 → long-range dependencies
  • Head 3 → local context (nearby words)
  • Head 4 → coreference ("it" → "animal")

Parallelism

All heads are computed simultaneously — no sequential dependency. Each head operates on a different learned projection of the same input. After parallel computation, all head outputs are concatenated.

Final Projection

The concatenated output may have higher dimension. It is projected back to model dimension using weight matrix W^O. This gives one attention vector per word to feed into the Feed Forward Network.

9 Residual Connections & Layer Normalization

Residual Connections

Output = LayerNorm(x + Sublayer(x))

Applied after every sub-layer (attention and FFN) in both encoder and decoder. Serves two purposes:

  • Knowledge Preservation: During forward propagation, the input gets heavily modified. Residual connections ensure old information is not lost — the original input is added back.
  • Vanishing Gradients: Provides a direct gradient highway from output to early layers, mitigating vanishing gradients during backprop.

Layer Normalization

Applied after residual addition. Normalizes across the feature dimension (each sample's own features), not across the batch.

Unlike Batch Normalization (normalizes per feature across all samples in a batch), Layer Normalization normalizes per sample across all features — same mean and std for all feature dimensions of one sample.

Why Layer Norm? Works better for sequences of variable lengths and doesn't depend on batch size.

Parallelism Benefit

Because of the self-attention mechanism (no sequential dependency), all words in the encoder block can be processed simultaneously. We can pass all words together and get all outputs together — this is the fundamental parallelism advantage over RNNs.

11 Exam Q&A
🎓 Fundamentals
Q1: What is a Transformer and how does it differ from RNN/LSTM? ▼

A Transformer is a non-recurrent neural network that processes all tokens in a sequence in parallel using attention mechanisms. Unlike RNNs/LSTMs which process tokens sequentially (one at a time) and suffer from slow training and vanishing gradients on long sequences, Transformers:

  • Process the entire sequence in one step (parallelism)
  • Allow every token to directly attend to any other token regardless of distance
  • Are significantly faster to train on modern hardware
  • Use positional encoding to replace the implicit ordering of recurrence
Q2: Describe the overall architecture of a Transformer. ▼

A Transformer consists of an Encoder stack and a Decoder stack, each with N=6 identical layers.

Each Encoder layer contains: (1) Multi-Head Self-Attention, (2) Add & Norm, (3) Feed Forward Network, (4) Add & Norm.

Each Decoder layer contains: (1) Masked Multi-Head Self-Attention, (2) Add & Norm, (3) Encoder-Decoder Attention, (4) Add & Norm, (5) Feed Forward Network, (6) Add & Norm.

The decoder additionally has a Linear layer and Softmax at the top to produce word probability distributions.

Q3: Why can't Transformers capture positional information without positional encoding? ▼

Because Transformers process all tokens simultaneously (in parallel), there is no sequential ordering. The attention operation is permutation-equivariant — shuffle the input tokens and you get the same output vectors (just shuffled). Without positional encoding, "I am a robot" and "robot am I a" would produce identical representations. Positional encoding adds a unique position-specific vector to each word embedding so the model can distinguish positions and learn order-dependent relationships.

🎓 Encoder & Decoder
Q4: What is the role of the Encoder in a Transformer? ▼

The encoder's role is to produce contextualized representations of all input tokens. It takes the input sequence (with positional encoding) and passes it through N=6 layers of self-attention + feed-forward networks. Each encoder layer refines the representation — lower layers capture local syntactic relationships, higher layers capture global semantic relationships. The final encoder output is a matrix of vectors, one per input token, used as Keys (K) and Values (V) in the decoder's encoder-decoder attention.

Q5: What is the difference between the three types of attention in a Transformer? ▼

1. Encoder Self-Attention: Q, K, V all come from the same encoder layer. Each input token attends to all other input tokens. No masking. Purpose: build context-aware input representations.

2. Masked Decoder Self-Attention: Q, K, V from the decoder's own previous layer. Future positions are masked (−∞ before softmax → 0 after). Purpose: auto-regressive generation — can only use past tokens.

3. Encoder-Decoder Attention: Q comes from the decoder, K and V come from the encoder output. Purpose: lets the decoder align and focus on relevant parts of the source (input) sequence — the cross-language alignment in translation.

Q6: What is masking and why is it needed in the decoder? ▼

Masking in the decoder's self-attention sets the attention scores for all future positions to −∞ before applying softmax, which makes their softmax output → 0 (no attention to future tokens).

Why needed? During training, the full target sequence is fed to the decoder at once for parallelism. Without masking, at position j, the model could see the correct jth word (and beyond), making training trivial. Masking enforces: to predict word j, the model can only see words 1 to j-1. This mimics the actual inference scenario where future words haven't been generated yet.

🎓 Training
Q7: What is "shifting right" and why is it done during training? ▼

The decoder input is the target sentence shifted one position to the right, with a <START> token prepended.

Target: "De Nada <EOS>" Decoder input: "<START> De Nada" ← shifted right

Why? Without shifting, at position j the model would see the correct jth output token and learn to simply copy it — learning nothing. Shifting ensures: given tokens 1 to j-1, predict token j. This forces the model to actually learn to generate based on context rather than copy-pasting.

Q8: What is Teacher Forcing? What are its advantages and disadvantages? ▼

Teacher Forcing: During training, even if the decoder predicts the wrong word at step j, the correct word (from the target) is fed as input for step j+1. The wrong prediction is not used.

Analogy: Like a teacher who corrects a student's mistake immediately and continues with the correct context, rather than letting errors propagate.

Advantage: Faster, more stable training — the model always receives correct context, preventing error accumulation during training.

Disadvantage (Exposure Bias): At inference time, teacher forcing is off — the model uses its own (possibly wrong) previous predictions. This mismatch between training and inference can lead to error accumulation during generation.

Q9: Describe the Transformer inference/testing process. ▼

During inference (auto-regressive decoding):

  1. Encode the full input sentence → encoder output (fixed)
  2. Start decoder with <START> token → generate first output word
  3. Append that word to decoder input sequence
  4. Re-run decoder with updated sequence → generate next word
  5. Repeat until <EOS> is generated or max length reached

Unlike training (all tokens in parallel), inference is sequential because each word depends on all previously generated words.

🎓 Positional Encoding
Q10: Write and explain the positional encoding formula. ▼
P(k, 2i) = sin(k / n^(2i/d)) ← even indices P(k, 2i+1) = cos(k / n^(2i/d)) ← odd indices
  • k: position of token in sequence (0 to L-1)
  • i: dimension index (0 to d/2 - 1)
  • d: embedding dimension
  • n: scaling factor = 10,000 (original paper)
  • Even dims (2i) → sine function; Odd dims (2i+1) → cosine function

Why this design? Sine and cosine produce periodic patterns at different frequencies across dimensions. Each position gets a unique combination. The model can learn relative positions because sin(k+m) and cos(k+m) can be expressed as linear functions of sin(k) and cos(k).

Q11: What is the final input to the Transformer and why is addition used? ▼
Final Input = Word Embedding + Positional Encoding

Both vectors have the same dimensionality (d), so they can be directly added. This preserves the embedding dimension — no concatenation overhead. The addition allows positional information to be incorporated into each word's representation without creating a separate positional channel. The model learns to disentangle semantic meaning from positional information during training.

🎓 Attention Mechanisms
Q12: Derive and explain Scaled Dot-Product Attention step by step. ▼
Attention(Q, K, V) = softmax(QK^T / √dk) · V
  1. Project inputs: Q = X·W_Q, K = X·W_K, V = X·W_V (learned projections)
  2. Compute scores: QK^T → similarity between each query and all keys [seq×seq matrix]
  3. Scale: Divide by √dk → prevents large values saturating softmax
  4. Mask (optional): In decoder, set future positions to −∞
  5. Softmax: Convert scores to probabilities (each row sums to 1)
  6. Weighted sum: Multiply by V → context-aware representation for each position

Why scale by √dk? q·k has variance = dk. Large values push softmax into near-zero gradient regions. Scaling by 1/√dk restores variance to 1.

Q13: Why is Multi-Head Attention better than Single-Head Attention? ▼

Single-head attention learns only one attention distribution — one type of relationship. Natural language simultaneously has syntactic, semantic, and positional relationships that one head cannot capture well.

Multi-head attention benefits:

  • Different heads learn different relationship types in parallel
  • Richer, more informative representations
  • Heads operate on smaller dimensions (dk/h each), keeping computation similar to single-head
  • Improved positional learning — each head attends to different parts of the sequence

Example: For "The animal didn't cross the street because it was tired" — one head links "it"→"animal" (coreference); another captures "cross"→"street" (verb-object).

Q14: Compare Simple Attention vs Self-Attention. ▼

Simple (Encoder-Decoder) Attention: Used in traditional Seq2Seq with attention (Bahdanau). The decoder's Query attends to encoder outputs (K, V). Cross-sequence attention — decoder focuses on relevant parts of the encoder's source sequence. Used in older translation models, not Transformers.

Self-Attention: Q, K, V all come from the same sequence. Each token attends to all other tokens in the same sentence. Builds context-aware representations without needing a second sequence. Used in Transformers' encoder for source context, decoder for target context.

Key difference: Simple attention is cross-sequence; self-attention is within-sequence. Transformers use both — self-attention within encoder/decoder, and cross-attention between encoder output and decoder.

🎓 Residual Connections & Normalization
Q15: What are residual connections and why are they needed in Transformers? ▼
Output = LayerNorm(x + Sublayer(x))

Residual connections add the input x directly to the sublayer's output before normalization. Two purposes:

1. Knowledge Preservation: Deep networks modify inputs heavily through forward passes. The residual connection ensures the original input signal is always preserved — old information is not lost. The model learns a delta/correction rather than a full transformation.

2. Vanishing Gradients: In deep networks, gradients diminish as they propagate backward. Residual connections provide a direct gradient path from the output all the way to early layers, bypassing the multiplicative gradient chain.

Q16: Compare Batch Normalization vs Layer Normalization. Why does Transformer use Layer Norm? ▼

Batch Normalization: Normalizes each feature across the batch dimension. Computes mean and std per feature, same for all training examples in the batch. Problem: depends on batch size; doesn't work well for variable-length sequences.

Layer Normalization: Normalizes across the feature dimension for each individual sample. Computes mean and std per sample (same for all feature dimensions). Doesn't depend on batch size or sequence length.

Why LN in Transformers? NLP has variable-length sequences. Small batches during inference make batch statistics unreliable. Layer norm is more stable for sequential data and works with batch size = 1 during inference.

🎓 Additional Important Questions
Q17: How does the Transformer achieve parallelism? Why can't RNNs do this? ▼

RNNs: The hidden state at time t depends on the hidden state at t-1. This sequential dependency means tokens must be processed one at a time — token 2 cannot start until token 1 is complete. This is fundamentally sequential and cannot be parallelized.

Transformers: Self-attention computes the relationship between all token pairs simultaneously — QK^T is a matrix multiplication that computes all pairwise similarities at once. No sequential dependency. All encoder tokens are processed simultaneously. All decoder tokens (with masking) are also processed simultaneously during training. GPUs excel at exactly this kind of matrix multiplication → massive speedup.

Q18: What is the purpose of the Feed Forward Network in each Transformer layer? ▼

The Feed Forward Network (FFN) in each layer serves two purposes:

1. Non-linearity: Attention is a weighted average — a linear operation. The FFN introduces non-linearity through its activation function (ReLU), allowing the model to learn complex non-linear transformations.

2. Transformation: The FFN transforms the attention output into a form suitable for the next encoder/decoder layer. It is applied position-wise independently — the same FFN parameters are applied to each position separately. This is where most of the model's "memory" capacity is stored.

FFN(x) = max(0, xW₁ + b₁)W₂ + b₂ ← ReLU activation
Q19: What is the role of the Linear and Softmax layers at the Transformer output? ▼

Linear Layer: The final decoder output has dimension d_model (e.g., 512). The linear layer projects it to the full vocabulary size (e.g., 30,000 dimensions for a large vocabulary). Each output neuron corresponds to one word in the vocabulary.

Softmax Layer: Converts the raw linear scores (logits) into a proper probability distribution over the vocabulary. All values are between 0 and 1, summing to 1. The word with the highest probability is selected as the predicted next token (greedy decoding), or beam search is used to find a better overall sequence.

Q20: What is "Attention is All You Need" — summarize the key contributions of the original Transformer paper. ▼
  1. Eliminated recurrence — replaced RNN/LSTM with pure attention, enabling full parallelization
  2. Scaled Dot-Product Attention — efficient QKV attention mechanism
  3. Multi-Head Attention — parallel attention heads for richer representations
  4. Positional Encoding — sinusoidal encoding to replace sequential position information
  5. Encoder-Decoder architecture with N=6 stacked layers each
  6. Residual connections + Layer Normalization after every sublayer
  7. Achieved state-of-the-art on machine translation while being much faster to train
  8. Foundation for BERT, GPT, T5 and essentially all modern large language models
