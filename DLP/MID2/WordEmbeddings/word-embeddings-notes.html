01 — Foundation

Introduction to Word Encodings

Neural networks require data in numerical form. For images, we use pixel values. For text, we need a strategy — that strategy is word encoding.

Definition

Word Encoding is the process of representing words (or any text) in a numerical form that can be fed into a neural network.

Images
  • Pixel values (0–255)
  • RGB channels
  • Directly numerical
Text
  • Needs encoding strategy
  • Categorical by nature
  • Requires numerical mapping
02 — Technique

One-Hot Encoding

One-hot encoding is the most fundamental technique. Each word is represented as a binary vector with a single 1 at its position and 0s everywhere else.

Key Rule

For a vocabulary of N unique words, each word becomes a vector of length N — with exactly one 1.

03 — Mathematics

Distance Metrics Between Vectors

To measure how similar or different two word vectors are, we use the following distance/similarity functions where A and B are vectors:

1. Cosine Similarity

Measures the angle between two vectors. Returns a value between -1 and 1 (1 = identical direction).

Formula
cos(θ) = A · B / (‖A‖ · ‖B‖)
= Σ(AᵢBᵢ) / √Σ(Aᵢ²) · √Σ(Bᵢ²)
📐
Worked Example

X = (5,9,3,0,2,0,0,2,0,0)
Y = (3,0,2,0,1,1,0,1,0,1)
Cosine Similarity ≈ 0.94 (very similar!)

2. Jaccard Similarity

Measures overlap between two sets. Ratio of intersection to union.

Formula
J(A, B) = |A ∩ B| / |A ∪ B|

3. Euclidean Distance

Straight-line distance between two points in n-dimensional space.

Formula
d(A, B) = √ Σᵢ (Aᵢ − Bᵢ)²

4. Manhattan Distance

Sum of absolute differences — like navigating a city grid.

Formula
d(A, B) = Σᵢ |Aᵢ − Bᵢ|
04 — Limitations

Issues with One-Hot Encoding

01
Sparse & High-Dimensional
The vector length equals the total number of unique words in the vocabulary. For 10,000 words, every vector has 9,999 zeros and one 1. Extremely wasteful in memory.
02
No Semantic Relationship
Distance between Lion and Tiger is the same as between Lion and Fish. The encoding carries zero meaning about word similarity.
03
Zero Dot Products
Any dot product between two different one-hot vectors is always 0. The model cannot learn word relationships from this.
⚠️
Classic Problem

Consider:
"I want a glass of Orange ____"
"I want a glass of Apple ____"

Both likely end in "juice". But with one-hot encoding, Orange and Apple appear completely unrelated — their vectors have zero similarity. The model can't generalize across these synonymous contexts.

05 — Core Concept

Word Embeddings

Word embeddings are dense, lower-dimensional vector representations of words that capture both semantic and syntactic relationships.

// High-Dimensional → Dense Embedding Space

Why Use Word Embeddings?

🧠
Semantic Meaning
Similar words cluster closer in vector space
📉
Dimensionality Reduction
10,000 dims → 300 dims (much denser)
🔁
Transfer Learning
Pre-trained embeddings reusable across NLP tasks
📈
Better Generalization
Models learn from word relationships
06 — Representation

Featurized Representation

Each word gets a 300-dimensional feature vector where each dimension captures some linguistic property (gender, royalty, age, food, size, cost…).

💡
Key Idea

The embedding matrix E has dimensions 300 × 10,000. For any word with one-hot vector Oⱼ, multiplying E · Oⱼ extracts the 300-dim feature vector eⱼ for that word.

Feature Man Woman King Queen Apple Orange
Gender −1 +1 −0.95 +0.97 0.00 0.01
Royal 0.01 0.02 0.93 0.95 −0.01 0.00
Age 0.03 0.02 0.70 0.69 0.03 −0.02
Food … … … … … …

✦ Notice: Man/Woman share similar Age & differ strongly in Gender. King/Queen share high Royalty scores. Apple/Orange are near-zero in Gender & Royalty.

Famous Word Analogy

eKing − eMan + eWoman ≈ eQueen
Also: Boy − Man + Woman ≈ Girl

If the feature vectors are learned correctly, they encode linear relationships between semantic concepts.

07 — Architecture

Neural Network for Learning Embeddings

Given the sentence "I want a glass of Orange ___", we learn embeddings by training a language model to predict the next word.

Input Encoding Process

I(4343) → O₄₃₄₃ → E → e₄₃₄₃
want(9665) → O₉₆₆₅ → E → e₉₆₆₅
a(1) → O₁ → E → e₁
glass(3852) → O₃₈₅₂ → E → e₃₈₅₂
of(6163) → O₆₁₆₃ → E → e₆₁₆₃
orange(6257) → O₆₂₅₇ → E → e₆₂₅₇
// Embedding Neural Network Architecture

Layer Breakdown

L1
Input Layer — One-Hot Encodings
Each input word is represented as a one-hot vector of length 10,000. For 6 input words, we have 6 such vectors.
L2
Embedding Layer — Matrix E
The embedding matrix E (300 × 10,000) maps each one-hot vector to a dense 300-dim feature vector. This layer has 10,000 neurons.
L3
Feature Vector Layer — e
Each word produces a 300-dim embedding. For 6 input words, this concatenates to a 1800-dim vector. The weights here represent the word features.
L4
Output Layer — Softmax
Softmax over 10,000 vocabulary words gives probability distribution over the next word. The target is a one-hot vector of "juice".
🎯
Training Insight

The weights learned during backpropagation are the embedding vectors. We use a fixed-size window to handle variable sentence lengths. The goal is to learn E — the embedding matrix.

09 — Deep Dive

CBOW vs Skip-gram

Variant 01

Continuous Bag of Words

Predicts the target/center word from surrounding context words using a sliding window.

SENTENCE
The cat sat on the mat
WINDOW
["The", "sat", "on", "the"]
→ predict → "cat"
Advantages
✓ Faster to train
✓ Works well with frequent words
Variant 02

Skip-gram

Given a target word, predicts the surrounding context words in a fixed window. Predicts multiple words.

SENTENCE
The cat sat on the mat
TARGET
"cat" → predict →
["The", "sat", "on", "the"]
Advantages
✓ Better for rare words
✓ Captures complex relationships
// CBOW vs Skip-gram — Architecture Comparison
Property CBOW Skip-gram
Direction Context → Word Word → Context
Training Speed Faster Slower
Rare Words Weaker Stronger
Outputs per step 1 word Multiple words
Best for Frequent words Complex relationships
10 — Preprocessing

Tokenization & Preprocessing

Before training Word2Vec, text must be preprocessed. Here's the pipeline with a worked example:

📄
Dataset

"Deep learning is amazing. Machine learning is powerful."

Step 1 — Tokenize

Convert the text into a list of individual words (tokens):

Python 
# Input sentence
text = "Deep learning is amazing. Machine learning is powerful."

# Tokenize into list of words
corpus = ["Deep", "learning", "is", "amazing",
           "Machine", "learning", "is", "powerful"]

Step 2 — Build Vocabulary

Extract all unique words and sort them:

Python 
vocab = sorted(set(corpus))
print(vocab)

# Output:
# ['Deep', 'Machine', 'amazing', 'is', 'learning', 'powerful']
#  ← 6 unique words in vocabulary →

Step 3 — Assign Word Indices

Create two bidirectional dictionaries:

Python 
# Word to index mapping
word2idx = {word: idx for idx, word in enumerate(vocab)}

# Index to word mapping
idx2word = {idx: word for word, idx in word2idx.items()}

# Result:
# word2idx = {'Deep':0, 'Machine':1, 'amazing':2,
#              'is':3,  'learning':4, 'powerful':5 }
# idx2word = {0:'Deep', 1:'Machine', 2:'amazing',
#              3:'is',   4:'learning', 5:'powerful'}

Core Takeaway

Word embeddings solve the two fundamental flaws of one-hot encoding — sparse dimensionality and lack of semantic relationships — by learning dense, meaningful vector representations through a neural network trained to predict words in context.
