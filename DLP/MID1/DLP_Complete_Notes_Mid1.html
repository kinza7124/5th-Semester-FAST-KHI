Chapter 01

Fundamentals of Machine Learning

1.1 AI vs ML vs DL — The Big Picture

🧠 Intuition
Think of it as nested circles: AI ⊃ ML ⊃ DL. Every DL algorithm is ML, and every ML algorithm is AI — but not vice versa.
TermFull FormDefinitionExample
AI Artificial Intelligence Creating machines that simulate human thinking, problem-solving, and cognitive behavior Chess-playing computer, self-driving cars
ML Machine Learning Subset of AI; gives computers the ability to learn from data using statistical models without explicit programming (Arthur Samuel, 1959) Email spam detector, house price prediction
DL Deep Learning Subset of ML; eliminates need for feature engineering by using neural networks (inspired by human brain) Face recognition, ChatGPT, image classification
🔑 Key Distinction
Traditional Programming: Data + Program → Computer → Output
Machine Learning: Data + Output → Computer → Program (the rules are learned)

1.2 Types of ML Problems

Supervised Learning

Data is labeled. The model learns a mapping from input features to output labels.

  • Classification: Predict a discrete class (e.g., grade A/B/C, spam/not-spam)
  • Regression: Predict a continuous value (e.g., house price, salary)

Unsupervised Learning (Clustering)

Data is not labeled. We find patterns and groupings ourselves.

📌 K-Means Algorithm — Step by Step
Goal: Given N unlabeled data points, group them into K clusters.

1
Decide the number of clusters K
2
Randomly pick K points as initial centroids C₁, C₂, …, Cₖ
3
Assign each data point to the nearest centroid (using Euclidean or Manhattan distance)
4
Recompute each centroid as the mean of all points assigned to it
5
Repeat steps 3–4 until centroids stop moving (convergence)

1.3 Features & Feature Engineering

A feature is an attribute (column) of a data point. Choosing the right features is critical.

⚠️ Warning
Too many features → Overfitting. Irrelevant features (e.g., eye color for grade prediction) add noise without adding signal.

"All models are wrong, but some are useful." — George Box

The data pipeline is always split into:

Training Data

Used to train the model and learn weights/parameters

Validation Data

Used during training to check accuracy on unseen data; guides hyperparameter tuning

Test Data

Used after training to evaluate final model quality. Never used during model design!

1.4 Distance Metrics

Used to measure similarity/dissimilarity between data points.

Manhattan Distance
d = |x₂−x₁| + |y₂−y₁|

Sum of absolute differences. Preferred for high-dimensional data. Like navigating city blocks.

Example: P(2,3), Q(6,8) → |6−2| + |8−3| = 4+5 = 9

Euclidean Distance
d = √[(x₂−x₁)² + (y₂−y₁)²]

Straight-line (as the crow flies) distance. For n-dimensional data: √Σ(xᵢ−yᵢ)²

Example: P(2,3), Q(6,8) → √(16+25) = √41 ≈ 6.40

Accuracy
= (TP + TN) / (TP+TN+FP+FN)

Overall fraction of correct predictions. Misleading on imbalanced data!

Precision
= TP / (TP + FP)

"Of all I said were positive, how many actually were?" High precision = few false alarms.

Recall (Sensitivity)
= TP / (TP + FN)

"Of all actual positives, how many did I catch?" High recall = miss very few positives.

F1-Score
= 2 × (P × R) / (P + R)

Harmonic mean of Precision & Recall. Useful when you care about both equally.

📌 When to use Precision vs Recall?
High Recall critical → When a False Negative is very costly. Examples: cancer detection (missing a positive case = dangerous), fraud detection.

High Precision critical → When a False Positive is very costly. Examples: spam filter (don't want important emails deleted), YouTube content moderation.

Threshold & Precision-Recall Tradeoff

A classifier outputs probability p(y=1|x). We choose a threshold t:

If p(y=1|x) ≥ t → Predict Positive
If p(y=1|x) < t → Predict Negative
Strict threshold (t = 0.9)
  • Fewer positives predicted
  • FP ↓ → Precision ↑
  • FN ↑ → Recall ↓
  • Result: High precision, low recall
  • "When I say spam, I'm usually right — but many spams slip through"
Relaxed threshold (t = 0.3)
  • More positives predicted
  • FN ↓ → Recall ↑
  • FP ↑ → Precision ↓
  • Result: High recall, low precision
  • "I catch most spam — but some normal emails get flagged"

Class Imbalance

⚠️ Classic Trap
Suppose 990 negative samples and 10 positive. A model that always predicts negative achieves 99% accuracy — but is completely useless! This is the class imbalance problem. Use Precision, Recall, and F1 instead of accuracy in such cases.

2.1 The Biological Inspiration & BIP (Basic Ideal Perceptron)

💡 Intuition
A biological neuron receives signals, combines them, and fires (or doesn't). An artificial neuron (perceptron) does the same: it takes inputs, computes a weighted sum, applies a threshold function (activation), and produces an output.

The BIP (Basic Ideal Perceptron) is the smallest computational unit in a neural network:

  • Takes multiple inputs x₁, x₂, …, xₙ
  • Computes a weighted sum (strength of signal)
  • Adds a bias term
  • Passes through an activation function
  • Outputs ŷ

📌 Why Multiple Hidden Layers?
  • Expressiveness: Multiple neurons in same layer → learn multiple features in parallel
  • Abstraction: Earlier layers learn simple features (edges), deeper layers learn complex features (faces, objects)
  • Non-linearity is crucial: Without non-linear activations, stacking layers is pointless — the whole thing collapses to a single linear model

2.3 Activation Functions — Complete Guide

Activation functions introduce non-linearity. Without them, no matter how deep the network, it's just a linear model.

1. Sigmoid (Logistic)
σ(z) = 1 / (1 + e⁻ᶻ)
  • Output: (0, 1) — can be interpreted as probability
  • Threshold at 0.5: ≥0.5 → class 1, <0.5 → class 0
  • Derivative: σ'(z) = σ(z)(1 − σ(z))

USE: Binary classification output layer

⚠ Vanishing gradient for large |z|

2. Softmax
σ(zᵢ) = eᶻⁱ / Σⱼ eᶻʲ
  • Output: (0,1) for each class
  • Sum of all outputs = 1 (valid probability distribution)
  • Generalizes sigmoid to multi-class

USE: Multi-class classification output layer

3. ReLU
ReLU(z) = max(0, z)
  • If z < 0: output = 0
  • If z ≥ 0: output = z
  • Fast, no exponentials needed

USE: Hidden layers (most common default)

⚠ Dying ReLU problem

4. Leaky ReLU
f(z) = z if z>0, αz if z≤0
  • α is small constant, typically 0.01
  • Fixes dying ReLU: non-zero gradient for z < 0
  • Piecewise linear (NOT fully linear!)

USE: Hidden layers when ReLU neurons die

5. Tanh
tanh(z) = (eᶻ − e⁻ᶻ) / (eᶻ + e⁻ᶻ)
  • Output: (−1, 1) → zero-centered
  • Smoother gradients than sigmoid
  • Bounded outputs

USE: RNNs, some hidden layers

⚠ Vanishing gradient for large |z|

🔑 Multi-class vs Multi-label
Multi-class: One of many classes. E.g., animal is dog OR cat OR fish. Sum of probabilities = 1. Use Softmax.

Multi-label: Can belong to multiple classes simultaneously. E.g., chest X-ray can show TB AND COVID. Sum of probabilities can be >1. Use Sigmoid per output neuron.

2.4 Forward Propagation

Forward propagation is the process of computing predictions by passing input through all layers from input → output.

📌 Why do we separate z (pre-activation) from a (activation)?
Backpropagation uses derivatives of activation functions. Separating z and a makes the math cleaner and allows swapping activation functions without changing the linear part.

For a network with hidden layers:

Layer l computation:

z⁽ˡ⁾ = W⁽ˡ⁾ · a⁽ˡ⁻¹⁾ + b⁽ˡ⁾ ← linear combination (pre-activation)
a⁽ˡ⁾ = σ(z⁽ˡ⁾) ← apply activation function

Full forward pass:
z⁽¹⁾ = W⁽¹⁾x, a⁽¹⁾ = σ(z⁽¹⁾)
z⁽²⁾ = W⁽²⁾a⁽¹⁾, a⁽²⁾ = σ(z⁽²⁾)
ŷ = σ(W⁽³⁾a⁽²⁾)

Where wljk = weight between j-th node at layer l and k-th node at layer (l−1).

2.5 Loss Functions & Cost Functions

💡 Error vs Loss vs Cost — Clarified
Error: Difference for one sample → ŷ − y
Loss Function: Maps error to a non-negative scalar for one sample → L(y, ŷ)
Cost Function J(θ): Average of loss over ALL training samples → (1/N) Σ L(y⁽ⁱ⁾, ŷ⁽ⁱ⁾)
MSE (Regression)
J = (1/N) Σ(yᵢ − ŷᵢ)²

Mean Squared Error. Penalizes large errors more heavily (squares them). Sensitive to outliers.

MAE (Regression)
J = (1/N) Σ|yᵢ − ŷᵢ|

Mean Absolute Error. Less sensitive to outliers than MSE.

Binary Cross Entropy
L = −[y·log(ŷ) + (1−y)·log(1−ŷ)]

For binary classification with sigmoid output. Penalizes confident wrong predictions.

Categorical Cross Entropy
L = −Σᵢ yᵢ · log(ŷᵢ)

General formula for multi-class. Only the correct class term survives (one-hot targets).

📌 Why Cross Entropy over MSE for classification?
For a classification problem using sigmoid/softmax, MSE creates flat gradients (slow learning) when the prediction is very wrong. Cross entropy has steep gradients when predictions are confidently wrong → faster learning.

2.6 Backpropagation

💡 Intuition
Backpropagation is the algorithm that computes how much each weight contributed to the error, then adjusts weights to reduce the error. It works backward — from output layer to input layer — using the chain rule of calculus.

The Chain Rule — Foundation of Backprop

If y = f(u) and u = g(x), then:

dy/dx = (dy/du) · (du/dx)

Weight Update Rule

Core Formula ΔW = −α · (∂E/∂W)

W_new = W_old − α · (∂E/∂W)
  • α (alpha) = Learning rate = step size
  • ∂E/∂W = Gradient = slope of error w.r.t. weight
  • Negative sign = Move opposite to gradient (to decrease error)
🔑 Why move opposite to gradient?
The gradient points in the direction of steepest increase of the cost function. To minimize cost, we move in the opposite direction.

Sigmoid Derivative (used in backprop)

σ'(y) = σ(y) · (1 − σ(y)) = y · (1 − y)

This is why sigmoid causes vanishing gradients: for y ≈ 0 or y ≈ 1, the derivative ≈ 0 → tiny gradient updates.

2.7 Gradient Descent Variants

MethodHow it worksProsCons
Batch GD Uses entire dataset to compute gradient; updates weights once per epoch Stable, fewer oscillations Very slow for large datasets; may get stuck in local minima
SGD Randomly selects ONE data point; computes gradient for that point Fast, can escape local minima, computationally efficient High oscillations, may not converge to global minimum
Mini-Batch GD Divides dataset into small batches; updates per batch Balance of stability and speed; approximates global minimum Requires tuning of batch size
📌 Key Terminology
Epoch: One complete pass of the ENTIRE training dataset through the network (forward + backward)
Batch size: Number of training samples processed in one forward/backward pass
Iteration: One update of model parameters using a single batch
Example: 2000 samples, batch size 500 → 1 epoch = 4 iterations

2.8 Vanishing & Exploding Gradient Problem

⚠️ Critical Problem
In theory, deeper networks → lower training error. In practice, too deep → training error increases due to vanishing/exploding gradients.

Vanishing Gradient: During backprop, the chain rule multiplies many small derivatives together. For sigmoid/tanh activations, these derivatives are < 1. Multiplying many numbers < 1 → exponentially small gradient → early layers barely update → training stalls.

Exploding Gradient: If weights are initialized too large, gradients grow exponentially → model becomes unstable.

Solutions to Vanishing Gradient
  • Use ReLU (constant gradient for z > 0)
  • Batch Normalization
  • Skip/Residual connections (ResNet)
  • Careful weight initialization (e.g., He init: variance = 2/n)
Common Confusion

Overfitting ≠ Vanishing Gradient

In overfitting, training error is LOW but test error is HIGH.
In vanishing gradient, training error itself is HIGH (the model can't even learn the training data well).

Chapter 03

Convolutional Neural Networks (CNN)

3.1 Why CNN? Problems with MLP for Images

Suppose we have a 1 MP (1024×1024) image:

  • 1 MP = ~10⁶ input pixels
  • With 10⁶ neurons at input layer → 10¹² weights just for first layer
  • Computationally impossible to train
  • Also: MLP loses spatial information (where is the cat in the image?)
💡 CNN's Big Idea
Instead of connecting every pixel to every neuron, use a small filter that slides across the image, detecting local patterns (edges, textures). The same filter is applied everywhere → parameter sharing → massively fewer parameters!

3.2 The Convolution Operation

A filter (kernel) is a small matrix of learnable weights that slides over the input image.

📌 How Convolution Works
1
Place the filter at a position on the input
2
Perform element-wise multiplication between filter values and input values
3
Sum all products → one output value
4
Slide filter (by stride S) and repeat → produces a feature map

Output Size Formula

(Key Formula) Output Size = ⌊(n − f + 2P) / S⌋ + 1

Where:
n = input size (height or width)
f = filter size
P = padding
S = stride
📐 Example: Output Size Calculations

Example 1: Input 4×4, Filter 2×2, Stride 1, Padding 0

Output = (4 − 2 + 0)/1 + 1 = 3×3

Example 2: Input 150×150, Filter 3×3, Stride 1, Padding 0

Output = (150 − 3 + 0)/1 + 1 = 148×148

Example 3 (with Padding): Input 150×150, Filter 3×3, Stride 1, Padding 1

Output = (150 − 3 + 2)/1 + 1 = 150×150 (same padding!)

Convolution on RGB Images

An RGB image has shape: H × W × 3 (3 channels). The filter must also have 3 channels (H_f × W_f × 3).

Process:

  1. Apply filter channel to corresponding image channel → 3 separate element-wise products
  2. Sum the products from all 3 channels + bias → one output pixel
  3. Result: 3D input → 2D feature map (one per filter)

The third dimension (depth) of the output = number of filters applied.

Activation After Convolution

Z = W ∗ X + b ← convolution result (pre-activation)
A = ReLU(Z) = max(0, Z) ← feature map (post-activation)

ReLU is used because it introduces non-linearity and suppresses negative values (irrelevant features).

3.3 Stride & Padding

Stride

Stride = how many pixels the filter moves at each step.

  • Stride 1 → filter moves 1 pixel at a time → output is close to input size
  • Stride 2 → filter moves 2 pixels → output is half the input size (dimensionality reduction)

Padding

Adding zeros around the border of the input before convolution.

Without Padding (Valid)
  • Output shrinks each layer
  • Corner pixels used fewer times → less influential
  • Edge information is lost
With Padding (Same)
  • Output keeps same spatial size
  • All pixels (including edges) contribute equally
  • Choose P = (f−1)/2 for same padding

3.4 Pooling — Dimensionality Reduction

💡 Purpose of Pooling
Pooling reduces the spatial size of feature maps → fewer parameters → faster training → less overfitting. It also provides translation invariance (small shifts in input don't change output much). Pooling has NO learnable parameters!
Max Pooling

Takes the maximum value in each pooling window.

Example: 2×2 window:

[10 11] [14 12] → max([10,11,14,12]) = 14

Preserves the most prominent features. Most common in modern CNNs.

Average Pooling

Takes the average value in each pooling window.

Example: 2×2 window:

[10 11 14 12] → avg = 11.75

Smoother, used in LeNet and sometimes at the end of networks.

Pooling also uses the output size formula: Output = ⌊(n − f)/S⌋ + 1 (no padding in pooling)

3.5 Parameter Count in CNN Layers

(CNN Param Formula) Parameters = (f × f × Cᵢₙ) × Cₒᵤₜ + Cₒᵤₜ

f = filter size, Cᵢₙ = input channels, Cₒᵤₜ = number of filters
Extra Cₒᵤₜ = one bias per filter
📐 Parameter Calculation Examples

Conv Layer 1: Input 150×150×3, Filter 3×3, 16 filters

Params = (3×3×3) × 16 + 16 = 27×16 + 16 = 432 + 16 = 448

Conv Layer 2: Input 74×74×16, Filter 3×3, 32 filters

Params = (3×3×16) × 32 + 32 = 144×32 + 32 = 4608 + 32 = 4640

Conv Layer 3: Input 36×36×32, Filter 3×3, 64 filters

Params = (3×3×32) × 64 + 64 = 288×64 + 64 = 18432 + 64 = 18496

Max Pooling: Parameters = 0 (no learnable params!)

Dense Layer: 18496 flattened inputs → 512 neurons

Params = (18496 × 512) + 512 = 9,470,464 ← over 99% of total params!

⚠️ Key Insight
Dense layers dominate parameter count because each neuron connects to ALL neurons in the previous layer. CNN layers are efficient because they share parameters via filters.

3.6 Batch Normalization (BN)

💡 Problem it solves: Internal Covariate Shift
During training, after each mini-batch, weights update → the input distribution to deeper layers keeps changing. Each layer must constantly re-adapt to this shifting distribution. This is called Internal Covariate Shift. It slows training and causes vanishing/exploding gradients.

Batch Normalization normalizes the output of each layer before passing it to the next layer, using the mean and variance of the current mini-batch.

📌 BN Mathematical Steps
1
Compute batch mean: μ_B = (1/m) Σ xᵢ
2
Compute batch variance: σ²_B = (1/m) Σ(xᵢ − μ_B)²
3
Normalize: x̂ᵢ = (xᵢ − μ_B) / √(σ²_B + ε) ← ensures numerical stability
4
Scale & shift (learnable): yᵢ = γ·x̂ᵢ + β ← γ (scale), β (shift) learned via backprop
Benefits of BN
  • Reduces vanishing gradient problem
  • Reduces exploding gradient problem
  • Stabilizes training
  • Allows higher learning rates
  • Acts as mild regularization
Normalization vs Batch Norm
NormalizationBatch Norm
Applied onEntire datasetMini-batch
LocationInput dataHidden layers
Used forBefore trainingInside network
LearnableNoYes (γ, β)

BN is typically applied: Linear → BN → ReLU

Mostly used in ResNet. Applied at hidden layers inside the network.

3.7 Overfitting, Underfitting & Regularization

💡 Intuition
Think of overfitting as memorizing the exam questions instead of understanding the subject — you do great on known questions but fail on new ones.
StateTraining AccuracyValidation AccuracyIssue
Underfitting Low Low High Bias — model too simple, hasn't learned enough
Good Fit High High (≈ Train) Low Bias, Low Variance — ideal!
Overfitting Very High Low High Variance — model memorized training data + noise

Dropout — Regularization Technique

📌 How Dropout Works

During each training iteration, randomly deactivate a fraction p of neurons (set to 0).

Dropout rate 50%: If activations = [a₁, a₂, a₃, a₄], random mask = [1,0,1,0], then:

After dropout: a' = [a₁, 0, a₃, 0] → neurons 2 and 4 are "dropped"

This prevents any single neuron from becoming excessively influential → forces the network to learn redundant representations → better generalization.

At test time: All neurons are active, but their outputs are scaled by (1 − dropout rate).

Without Dropout
  • Low training loss
  • High validation loss
  • Overfitting
With Dropout
  • Slightly higher training loss
  • Lower validation loss
  • Better generalization

L1 and L2 Regularization

Add a penalty term to the cost function to discourage large weights:

L2 (Ridge): J_reg = J + λ·Σ w²
L1 (Lasso): J_reg = J + λ·Σ|w|

Large weights → higher cost → model learns smaller weights → simpler model → less overfitting.

💡 When you don't have enough data…
Data augmentation artificially increases the training dataset by creating modified versions of existing data — instead of collecting new data.

4.2 ResNet — Residual Networks

⚠️ Problem ResNet Solves
In very deep networks (50+ layers), the vanishing gradient problem makes early layers learn very slowly. Also, "plain networks" (just stacking layers) degrade — adding more layers increases training error (counterintuitively). ResNet solves this with skip connections.

Skip Connections / Residual Connections

Normal layer: a(l+1) = g(z(l+1))
Residual block: a(l+2) = g(z(l+2) + a(l))

z(l+2) = W(l+2) · a(l+1) + b(l+2)
a(l+2) = g(z(l+2) + a(l)) ← adds the input directly to the output!
💡 Intuition Behind Skip Connections
The skip connection "shortcuts" the signal directly to later layers. Even if the intermediate layers learn nothing (gradient vanishes), the signal still flows through. At worst, the block learns an identity function → the network doesn't degrade with depth.

The block learns the residual F(x) = H(x) − x (what needs to be added to the input). That's why it's called a "residual" connection.
📌 ResNet Summary
  • Solves vanishing gradient by providing shortcut paths for gradients
  • Uses residual learning: learns what to add, not what to output
  • Enables training of very deep networks (50, 100, 152 layers)
  • Used in: image classification, object detection, medical imaging
  • Skip connections are also called "shortcut connections" or "identity shortcuts"

4.3 Inception Network (GoogLeNet)

💡 Motivation
For a dog image: sometimes the dog fills the whole frame, sometimes it's tiny in a corner. The "right" filter size depends on where the object is and how big it is. Inception's idea: use MULTIPLE filter sizes in parallel!

Core Idea of Inception Module

Instead of choosing one filter size, apply all of them simultaneously and concatenate:

  • 1×1 convolution → small/local features + dimension reduction
  • 3×3 convolution → medium features
  • 5×5 convolution → large features
  • 3×3 max pooling → pooled features

All outputs must have the same H×W dimensions (use padding). Concatenate along depth axis (Z dimension).

The Problem of Computational Cost

💰 Computational Cost Example

Scenario: Input 28×28×192, apply 32 filters of 5×5

Computations = 28×28×32 × 5×5×192 = 120 Million operations!

Solution: Add a 1×1 bottleneck convolution first

1
Apply 16 filters of 1×1×192 → result: 28×28×16 (reduce channels from 192 to 16)
Cost = 28×28×16 × 1×1×192 = 2.4 Million
2
Apply 32 filters of 5×5×16 on this → result: 28×28×32
Cost = 28×28×32 × 5×5×16 = 10 Million

Total = 12.4 Million — a 10× reduction!

🔑 Why 1×1 Convolution?
A 1×1 convolution doesn't change the spatial dimensions (H, W) but can change the number of channels (depth). It applies a learned linear combination across channels — acting as a cheap "bottleneck" to reduce computational cost before more expensive 3×3 or 5×5 convolutions.

N1: Backpropagation — Full Numerical

📌 Setup (from lecture notes)
A 2-input, 2-hidden, 2-output neural network.
x₁ = 0.05, x₂ = 0.10 (inputs), Target: t₁ = 0.01, t₂ = 0.99
Weights: w₁=0.15, w₂=0.25, w₃=0.20, w₄=0.30, w₅=0.40, w₆=0.45, w₇=0.50, w₈=0.55

🔢 Step 1: Forward Pass

Hidden neuron h1:

neth₁ = w₁·x₁ + w₂·x₂ + b₁ = (0.15)(0.05) + (0.10)(0.20) + 0.35 = 0.3775
h₁_out = σ(0.3775) = 1/(1+e⁻⁰·³⁷⁷⁵) ≈ 0.59326

Hidden neuron h2:

neth₂ = w₃·x₁ + w₄·x₂ + b₁ = (0.25)(0.05) + (0.30)(0.20) + 0.35 = 0.3925
h₂_out = σ(0.3925) = 1/(1+e⁻⁰·³⁹²⁵) ≈ 0.59688

Output neuron o1:

neto₁ = w₅·h₁ + w₆·h₂ + b₂ = (0.40)(0.59326) + (0.45)(0.59688) + 0.60
= 0.23730 + 0.26860 + 0.60 = 1.10590
o₁ = σ(1.10590) = 1/(1+e⁻¹·¹⁰⁵⁹) ≈ 0.75136

Output neuron o2:

neto₂ = (0.50)(0.59326) + (0.55)(0.59688) + 0.60 = 1.22491
o₂ = σ(1.22491) ≈ 0.77292
🔢 Step 2: Calculate Total Error
E_o1 = ½(t₁ − o₁)² = ½(0.01 − 0.75136)² = 0.27481
E_o2 = ½(t₂ − o₂)² = ½(0.99 − 0.77292)² = 0.02357
E_total = E_o1 + E_o2 = 0.29838
🔢 Step 3: Backpropagation — Output Layer

Gradient ∂E/∂w₅ (using chain rule):

∂E/∂w₅ = ∂E/∂o₁ · ∂o₁/∂neto₁ · ∂neto₁/∂w₅

∂E/∂o₁ = −(t₁ − o₁) = −0.01 + 0.75136 = 0.74136
∂o₁/∂neto₁ = o₁(1−o₁) = 0.75136 × (1−0.75136) = 0.18680 ← sigmoid derivative
∂neto₁/∂w₅ = h₁_out = 0.59326

δ_o1 = ∂E/∂o₁ × ∂o₁/∂neto₁ = 0.74136 × 0.18680 = 0.13850

∂E/∂w₅ = δ_o1 × h₁_out = 0.13850 × 0.59326 = 0.08216

Similarly: ∂E/∂w₆ = 0.13850 × 0.59688 = 0.08266

🔢 Step 4: Weight Update

Using learning rate α = 0.5:

w₅_new = w₅ − α · ∂E/∂w₅ = 0.40 − 0.5 × 0.08216 = 0.40 − 0.04108 = 0.35892

Interview Questions & QnA

Short Answer QnA

Q: Why do we use activation functions in neural networks?
Without activation functions, no matter how many layers you stack, the network is just a linear model (W₃·W₂·W₁·x is still a linear transformation). Activation functions introduce non-linearity, allowing the network to learn complex patterns. For example, ReLU replaces negatives with zero, creating piecewise linear boundaries.
Q: What is the dying ReLU problem and how is it fixed?
When a neuron consistently receives negative inputs, ReLU outputs zero for all inputs. The gradient is also zero → no weight update → the neuron "dies" and never recovers. Fix: Use Leaky ReLU: f(z) = αz for z ≤ 0 (α ≈ 0.01). This provides a small non-zero gradient even for negative inputs, keeping neurons alive.
Q: Why can't we use MSE loss for classification?
MSE creates a non-convex loss surface for classification tasks (with sigmoid/softmax outputs), leading to flat gradients when predictions are confident but wrong. Cross-entropy loss produces steeper gradients for wrong predictions, enabling faster learning. Cross-entropy is designed for probability distributions.
Q: Why does stacking more layers sometimes increase training error (not just test error)?
This is the degradation problem solved by ResNet. It's caused by the vanishing gradient problem — in very deep networks, gradients become exponentially small in early layers. Those layers barely update → the network can't learn even the training data effectively. ResNet's skip connections solve this by providing direct gradient pathways.
Q: What is internal covariate shift and how does Batch Normalization fix it?
During training, each mini-batch updates weights. This changes the input distribution to deeper layers — a phenomenon called Internal Covariate Shift. Each layer must constantly re-adapt to the new distribution, slowing training and causing gradient problems. BN normalizes the output of each layer using the mini-batch mean and variance, keeping the distribution stable. Learnable parameters γ and β allow the network to "undo" the normalization if needed.
Q: Why does precision decrease when we lower the classification threshold?
Lowering the threshold makes the model predict "positive" more often. This catches more true positives (recall ↑) but also incorrectly flags more negatives as positive (FP ↑). Since Precision = TP/(TP+FP), more FPs → lower precision. It's a fundamental tradeoff: you can't maximize both simultaneously (unless the model is perfect).
Q: What does "parameter sharing" mean in CNN and why does it matter?
In CNN, the same filter (set of weights) is applied to every position in the input image. All positions share the same parameters. This dramatically reduces the number of parameters compared to MLP (where every connection has a unique weight). For a 1MP image, MLP needs ~10¹² weights for just one hidden layer; a CNN might need just thousands. This makes CNNs trainable on reasonable hardware.
Q: Differentiate multi-class and multi-label classification.
Multi-class: Exactly one class applies. Example: digit recognition (0-9), only one digit is correct. Use Softmax — probabilities sum to 1.

Multi-label: Multiple classes can apply simultaneously. Example: a chest X-ray may show TB AND pneumonia AND COVID at once. Use Sigmoid for each output — each outputs independent probability, sum can exceed 1.
Q: Why is accuracy a bad metric for imbalanced datasets?
Consider 990 negatives, 10 positives. A "dummy" model predicting everything negative gets 99% accuracy. But it has recall = 0 (catches none of the positives). In medical diagnosis, this would mean missing every single disease case. Use F1-score, Precision, and Recall for imbalanced data evaluation.
Q: What does a 1×1 convolution do?
A 1×1 conv doesn't change spatial dimensions (H, W) but changes the number of channels. It applies a learned weighted combination across all channels at each spatial position. Used in Inception networks as a "bottleneck" to reduce channel depth cheaply before expensive 3×3 or 5×5 convolutions, dramatically reducing computation. Also adds a non-linear transformation at each pixel independently.

Interview Questions (Technical)

What are the key differences between SGD, Batch GD, and Mini-Batch GD?
SGD uses 1 sample per update (fast, noisy, can escape local minima). Batch GD uses entire dataset (stable but slow). Mini-Batch uses a subset (balances speed and stability, most used in practice). The oscillation pattern: SGD > Mini-Batch > Batch.
Explain the vanishing gradient problem and list 3 solutions.
During backpropagation through many layers, gradients become exponentially small (especially with sigmoid/tanh). Early layers get tiny updates → can't learn. Solutions: (1) ReLU activation — constant gradient for z > 0. (2) Batch Normalization — keeps activations in healthy range. (3) ResNet skip connections — provide direct gradient paths to early layers.
Why do CNN layers have fewer parameters than dense layers for image data?
CNN uses parameter sharing: same filter weights applied everywhere. For a 3×3 filter with 64 output channels and 32 input channels: only (3×3×32)×64 + 64 = 18,496 params regardless of image size. A dense layer connecting 148×148×64 = 1.4M neurons to 512 neurons needs 720M parameters. CNN params depend on kernel size and channel depth, not spatial dimensions.
What is the purpose of pooling in CNN and does it have learnable parameters?
Pooling reduces spatial dimensions (H×W) of feature maps, lowering computation and parameter count in subsequent layers. It also provides local translation invariance. Max pooling takes the maximum value in each window (preserves strongest feature). Average pooling averages values. No learnable parameters — pooling is a fixed operation.
What is the difference between overfitting and the vanishing gradient problem?
Overfitting: Training accuracy is HIGH, test accuracy is LOW — the model memorized training data including noise. The model is too complex for the data. Vanishing gradient: Both training AND test accuracy are poor — the model can't even learn the training data because gradients are too small to update early layers.
Explain why Inception applies multiple filter sizes in parallel.
Objects in images appear at different scales and in different positions. A 1×1 filter captures point features; 3×3 captures medium-scale features; 5×5 captures large features. Choosing one size risks missing features at other scales. By applying all sizes in parallel and concatenating, the network learns the most useful scale automatically for each image/task.
Explain Dropout — how does it prevent overfitting?
Dropout randomly disables neurons during each training batch. This prevents neurons from co-adapting (relying on specific other neurons). Each training iteration effectively trains a different "sub-network." The final model can be seen as an ensemble of many sub-networks → better generalization. At test time, all neurons are active but scaled by (1−dropout_rate) to compensate for more active neurons than during training.
What are the key properties of ReLU that make it preferred over sigmoid for hidden layers?
(1) No vanishing gradient for positive inputs (gradient = constant 1). (2) Computational efficiency — just max(0,z), no expensive exponentials. (3) Sparse activation — typically ~50% of neurons output 0 → sparse representation, efficient. (4) Faster convergence in practice. Sigmoid squashes outputs to (0,1) — multiplying many small derivatives → vanishing gradient.
