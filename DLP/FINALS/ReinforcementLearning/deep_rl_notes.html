The RL framework is modeled as a Markov Decision Process (MDP). The agent (athlete) interacts with the environment (athletic track) at each time step, choosing an action, receiving a reward, and observing the next state.

02 Action Space A = { Run, Jump, Stop } ▼

This is a Discrete Action Space — the agent picks one of three distinct choices at each time step.

🏃
ACTION 0
RUN
🦘
ACTION 1
JUMP
🛑

Because this is discrete, standard Q-Learning & DQN work perfectly — we can compute max Q-value across all 3 actions trivially.

Discrete vs Continuous Action Spaces:

TypeExamplesAlgorithmChallenge
DISCRETE Up/Down/Left/Right, Atari buttons, Chess moves Q-Learning, DQN None — max Q over finite set is easy
CONTINUOUS Accelerator (0–1), Robot joint angles (0°–180°), Temperature PPO, DDPG Can't take max over infinite actions

04 Reward Function R(s, a) ▼

The reward function guides learning by assigning numerical feedback to the agent's actions.

+1 Run → Moving forward
+10 Successfully clear a hurdle
−10 Hit / crash into hurdle
−1 Jump with no hurdle nearby
−1 Stay / Stop (wasting time)
Large penalties (−10) discourage dangerous collisions. Small rewards (+1) keep the agent moving efficiently. The asymmetry teaches when to jump, not just how.

06 Q-Learning & Bellman Equation ▼

The Q-value update uses the Bellman Equation to iteratively improve predictions:

Bellman Update Rule
Q(s,a) ← Q(s,a) + α [ r + γ · maxa' Q(s',a') − Q(s,a) ]
αLearning rate — how fast weights update
γDiscount factor — importance of future rewards
rImmediate reward received after action a
s'Next state after taking action a in state s
max QBest predicted reward in the next state
StepWhat Happens
1Agent observes state s (dist, vel, etc.)
2Agent picks action using ε-greedy policy (explore vs exploit)
3Environment returns reward r and next state s'
4Compute Target = r + γ · max Q(s', a')
5Compute Loss = (Target − Q(s,a))²
6Backpropagate loss to update network weights
07 Value-Based vs Policy-Based Learning ▼
Value-Based Policy-Based
Goal Learn V(s) or Q(s,a) Optimize π(a|s) directly
Policy Implicit (pick max value) Explicit (learned distribution)
Examples Q-Learning DQN REINFORCE PPO

Actor-Critic — modern hybrid combining both approaches:

🎭
Actor
Policy-based. Proposes an action π(a|s). Learns WHAT to do.
🧑‍⚖️
Critic
Value-based. Evaluates how good the action was via V(s). Learns HOW GOOD it was.
🌍
Environment
Returns reward r and next state s'. Provides the signal to both.
08 Algorithm Quick Reference ▼
Q-LEARNING
Value-Based · Model-Free · Tabular
  • Uses Q-Table
  • Discrete actions only
  • Small state spaces
  • Bellman updates
DQN
Value-Based · Deep · Discrete
  • Neural network replaces table
  • Experience Replay buffer
  • Target Network trick
  • Used in Atari games
REINFORCE
Policy-Based · Gradient · Stochastic
  • Learns policy directly
  • High variance
  • Works for continuous
  • Monte Carlo returns
PPO / DDPG
Actor-Critic · Continuous · SOTA
  • Continuous action spaces
  • Stable training (PPO clip)
  • DDPG: deterministic policy
  • Robotics & locomotion
