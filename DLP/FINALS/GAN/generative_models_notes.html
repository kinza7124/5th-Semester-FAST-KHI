1 Autoencoders

What is an Autoencoder?

An Autoencoder is an unsupervised neural network that learns to compress (encode) input data into a low-dimensional latent space z, then reconstruct (decode) it back. Since there are no labels, it uses the input itself as the target — self-supervised learning.

Fig 1: Autoencoder — Encoder compresses x→z, Decoder reconstructs z→x̂. Loss = MSE between input and output.

Encoder

Maps input x → z (latent space). A series of NN layers that progressively compress the data. Traditional AEs are deterministic — one fixed vector z per input.

Decoder

Maps latent z → x̂. Expands back to original dimensionality. Trained to minimize reconstruction loss: ℒ = ‖x − x̂‖²

Loss Function — RMSE/MSE

ℒ(x, x̂) = ‖x − x̂‖² For images: pixel-wise squared difference = Σ (original_pixel − reconstructed_pixel)²

The loss does not use any labels — the input is its own target. This is what makes it unsupervised.

Why a Bottleneck?

  • Forces compression: network must learn what's truly important
  • Learns compact representations: latent z = essence of the input
  • Without bottleneck: network could simply memorize/copy inputs
  • Trade-off: smaller z → harder to reconstruct → higher loss
Limitation: Traditional autoencoders are deterministic. z is a single fixed point per input — you cannot sample new, meaningful data from the latent space. That's why VAEs exist.
2 Variational Autoencoders (VAE)

Core Idea

Instead of encoding x to a single point z, a VAE encodes it to a probability distribution — specifically N(μ, σ²). We then sample z from this distribution to pass to the decoder. This makes the latent space smooth and continuous, enabling generation of new data.

Fig 2: VAE Architecture — Encoder outputs μ and σ², reparameterization trick computes z = μ + σ·ε, Decoder reconstructs x̂.

vs Regular AE — Key Difference

  • AE: z = single fixed vector (deterministic)
  • VAE: z ~ N(μ, σ²) (probabilistic)
  • VAE learns a distribution, not a point
  • VAE can generate new samples by sampling z

Properties of Latent Space

  • Continuity: nearby z → similar decoded output
  • Completeness: any sampled z → meaningful output
  • Without regularization: these properties break!

VAE Loss Function

ℒ(φ, θ, x) = Reconstruction Loss + Regularization Term = E_q[log p_θ(x|z)] − D_KL(q_φ(z|x) ‖ p(z)) ↑ ↑ How well decoder How close q(z|x) is reconstructs x to prior N(0,1)

Both terms must be minimized simultaneously. There is a trade-off: more regularization → smoother latent space but possibly lower reconstruction quality.

Reparameterization Trick — Why We Need It

Sampling z ~ N(μ, σ²) is non-differentiable — gradients cannot flow through a random sampling operation. Backprop requires deterministic behavior.

❌ Original (non-differentiable): z ~ q_φ(z|x) = N(μ, σ²) ✅ Reparameterized (differentiable): z = μ + σ · ε, where ε ~ N(0, 1) ε is constant (external noise) μ and σ are now the differentiable variables

This moves randomness into ε (which is sampled from a fixed distribution) while keeping μ and σ differentiable — so gradients can flow back through the network.

Fig 3: Reparameterization — Left: stochastic Z blocks backprop. Right: ε is external constant, gradients flow through deterministic Z = g(φ, x, ε).
Example: μ = 2, σ = 3, ε = 0.5 → z = 2 + 3 × 0.5 = 3.5. The randomness came from ε (fixed), so μ and σ remain differentiable.
3 KL Divergence

Definition

KL Divergence measures how different one probability distribution is from another. In VAEs, it measures the gap between the learned latent distribution q_φ(z|x) and the standard normal prior p(z) = N(0,1).

D_KL(q_φ(z|x) ‖ p(z)) = −½ Σⱼ₌₁ᵏ (1 + log σ²ⱼ − μ²ⱼ − σ²ⱼ) Each term explained: log σ²ⱼ → prevents variance collapsing to 0 −μ²ⱼ → penalizes mean moving away from 0 −σ²ⱼ → penalizes very large variance +1 → balancing constant from Gaussian formula −½ → scaling factor for correct magnitude
Fig 4: KL Divergence — measures gap between learned q_φ(z|x) and prior N(0,1). KL=0 when they perfectly overlap.

Role as Regularizer

  • Acts as a soft constraint on latent space
  • Pushes μ toward 0
  • Pushes σ² toward 1
  • Prevents encoder from "cheating" by memorizing
  • Ensures smooth, useful latent space

Without Regularization

  • Variance may collapse to zero (pointed distribution)
  • Means could diverge wildly from each other
  • Latent space loses continuity
  • Random sampling yields meaningless output

β-VAE Extension

ℒ(θ, φ; x, z, β) = E_q[log p_θ(x|z)] − β · D_KL(q_φ(z|x) ‖ p(z)) β > 1 → stronger regularization → more disentangled latent space β = 1 → standard VAE

Increasing β constrains the latent bottleneck, encouraging disentanglement — different dimensions of z encode independent interpretable features (e.g., smile, skin tone, gender).

Fig 5: Latent space without vs. with KL regularization. KL forces distributions to overlap, enabling smooth interpolation.
Numerical example: If μ=0, σ²=1 → each term: log(1)=0, μ²=0, σ²=1 → KL = −½(1 + 0 − 0 − 1) = 0. Perfect! If μ=3, σ²=0.01 → KL becomes large, penalizing this distribution.
4 VAE Loss & Latent Perturbation

Full VAE Loss Breakdown

ℒ(φ, θ, x) = Reconstruction Loss + Regularization Reconstruction = E_q_φ[log p_θ(x|z)] → for images: MSE = ‖x − x̂‖² → measures how faithfully decoder reconstructs x Regularization = D_KL(q_φ(z|x) ‖ p(z)) → = −½ Σ (1 + log σ²ⱼ − μ²ⱼ − σ²ⱼ) → keeps latent space near N(0,1)
Trade-off: Regularize too much → blurry reconstructions. Regularize too little → discontinuous latent space, can't generate new data. β-VAE balances this with the β hyperparameter.

Latent Perturbation

A powerful side effect of the smooth latent space: we can individually tune latent variables while keeping others fixed.

  • Each dimension of z encodes a different interpretable feature
  • Tune one z dimension → run decoder → get new output
  • Ideally: latent variables are uncorrelated (disentangled)
  • β-VAE enforces a diagonal prior to encourage independence
Fig 6: VAE encodes each facial attribute as a distribution, not a single point. Sampling generates diverse, realistic faces.
5 Generative Adversarial Networks (GANs)

Core Idea

Instead of modeling the density of data explicitly, GANs learn a transformation from noise to data. Two networks compete: a Generator G that creates fake data, and a Discriminator D that tries to detect it.

Fig 7: GAN — Generator creates fakes from noise z; Discriminator judges real vs fake. They compete until G fools D perfectly.

Objective Function (Minimax Game)

Discriminator maximizes (wants to correctly classify): arg max_D E_{z,x}[ log D(G(z)) + log(1 − D(x)) ] ↑ fake ↑ real Generator minimizes (wants to fool D): arg min_G E_{z,x}[ log D(G(z)) + log(1 − D(x)) ] Combined (minimax): arg min_G max_D E_{z,x}[ log D(G(z)) + log(1 − D(x)) ]

D(G(z)) = discriminator's estimate that fake sample is actually fake. D(x) = discriminator's estimate that real sample is fake. At global optimum: G reproduces true data distribution, D cannot distinguish real from fake.

Generator

  • Input: random noise vector z ~ N(0,1)
  • Output: fake sample G(z) ≈ real data
  • Cannot directly affect D(x) (real data)
  • Improves by making synthetic data realistic
  • After training: discard D, use G alone

Discriminator

  • Input: real x or fake G(z)
  • Output: probability of being fake/real
  • Gets better at spotting fakes during training
  • Forces G to improve continuously
  • Loss: cross-entropy (binary classification)

GAN Applications (from your notes)

1. Uncover underlying features

Given a facial dataset, group by features (skin color, age). Dataset may be biased; GANs can sample data accordingly to correct this.

2. Outlier Detection

Self-driving cars: detect novel/unknown situations. Train GAN on normal data; use it to flag outliers during inference.

Training dynamics: D gets better at classifying → forces G to be better at generating → forces D to improve again. This adversarial loop drives both networks to improve simultaneously.
6 Seq2Seq vs Autoencoder

Seq2Seq (Sequence-to-Sequence)

Seq2Seq is an encoder–decoder architecture designed for sequence transformation tasks (e.g., translation, summarization). The encoder compresses the input sequence into a context vector; the decoder generates a different output sequence — not necessarily the same as input.

Fig 8: Seq2Seq transforms one sequence into another (different). AE reconstructs the same input.

7 Exam Q&A
🎓 Autoencoder Questions
Q1: What is an Autoencoder and how is it trained? ▼

An Autoencoder is an unsupervised neural network with an encoder and decoder. The encoder compresses input x to a low-dimensional latent vector z; the decoder reconstructs x̂ from z. Training uses reconstruction loss ℒ = ‖x − x̂‖² (no labels). The bottleneck layer forces the network to learn a compressed, meaningful representation.

Q2: Why do we need a bottleneck in an Autoencoder? ▼

Without a bottleneck, the network could simply learn to copy the input (identity function), learning nothing useful. The bottleneck forces the network to learn a compact, meaningful representation — discarding noise and redundancies. Smaller bottleneck → harder compression → higher loss but more powerful feature learning.

Q3: Why can't we generate new data from a regular Autoencoder? ▼

Because the latent space z is deterministic. Each input maps to a single fixed point in latent space. There is no guarantee that points between those known locations decode into meaningful data — the latent space has no structure enforced on it. Random sampling from it gives garbage output.

🎓 VAE Questions
Q4: What is the key difference between an AE and a VAE? ▼

In AE: encoder outputs a single fixed vector z (deterministic). In VAE: encoder outputs a mean μ and variance σ², and z is sampled from N(μ, σ²). This probabilistic encoding, combined with KL divergence regularization, creates a smooth continuous latent space from which new data can be generated.

AE: z = encoder(x) [fixed point] VAE: z ~ N(μ(x), σ²(x)) [sample from distribution]
Q5: What is the Reparameterization Trick and why is it needed? ▼

Backpropagation requires deterministic, differentiable operations. Sampling z ~ N(μ, σ²) is neither — it's random and non-differentiable. The reparameterization trick reformulates:

z = μ + σ · ε where ε ~ N(0,1)

Now ε is an external constant (not a parameter), and μ, σ are the differentiable learned parameters. Gradients can flow through μ and σ normally. Example: μ=2, σ=3, ε=0.5 → z = 2 + 3(0.5) = 3.5

Q6: What are the two properties expected from VAE regularization? ▼

1. Continuity: Points that are close in latent space should produce similar reconstructions after decoding. If you move slightly in z space, the output should change smoothly.

2. Completeness: Any point sampled from the latent space should decode into meaningful content — no "holes" in the latent space that produce garbage.

Q7: What happens if we don't regularize the VAE? ▼

Without regularization, the model optimizes only reconstruction loss. This leads to:

  • Variance collapse: σ² → very small (pointed/delta distribution). The "distribution" degenerates into a single point like a regular AE.
  • Divergent means: μ values for different inputs could be far apart in latent space, creating discontinuities.
  • Randomly sampled z won't produce meaningful output.
🎓 KL Divergence Questions
Q8: Write and explain the KL Divergence formula for VAEs. ▼
D_KL = −½ Σⱼ (1 + log σ²ⱼ − μ²ⱼ − σ²ⱼ)
  • log σ²ⱼ: prevents variance from collapsing to zero
  • −μ²ⱼ: penalizes mean deviating from 0
  • −σ²ⱼ: penalizes variance becoming too large
  • +1: balancing constant from Gaussian formula
  • −½: correct scaling factor

Check: At μ=0, σ²=1: KL = −½(1 + 0 − 0 − 1) = 0 ✓

Q9: What is β-VAE and what does increasing β do? ▼
ℒ = Reconstruction − β · D_KL

β controls the strength of regularization. β > 1 applies stronger regularization to the KL term, which constrains the latent bottleneck more aggressively. This encourages disentanglement — each dimension of z encodes an independent, interpretable latent factor. Trade-off: β too large → reconstruction quality drops.

🎓 GAN Questions
Q10: Explain the GAN minimax objective and what each player optimizes. ▼
arg min_G max_D E[log D(G(z)) + log(1 − D(x))]

Discriminator D wants to maximize: correctly label fake G(z) as fake (high D(G(z))) and real x as real (high 1−D(x)). Generator G wants to minimize: make D(G(z)) close to 0 so D thinks the fake is real. At global optimum: G reproduces the true data distribution, D outputs 0.5 everywhere (can't distinguish).

Q11: Compare VAE and GAN for generative modeling. ▼
  • VAE: explicitly models distribution using KL divergence. Latent space is smooth and interpretable. Output can be blurry.
  • GAN: implicitly matches data distribution via adversarial game. Output is sharper and more realistic. Training can be unstable (mode collapse).
  • VAE is better for interpretability and disentanglement. GAN is better for high-quality image generation.
🎓 Seq2Seq Questions
Q12: How is Seq2Seq different from an Autoencoder? ▼

Autoencoder: Encoder–decoder trained to reconstruct the same input. No labels needed. Goal: learn compressed representation. Input = Output domain.

Seq2Seq: Encoder–decoder trained to transform one sequence to a different sequence. Requires parallel supervision (e.g., EN–FR sentence pairs). Goal: sequence transformation. Input ≠ Output domain.

Both use encoder–decoder architectures, but their objectives, losses, and supervision requirements are entirely different.

Q13: What are the 5 key capabilities of VAEs summarized from your lecture notes? ▼
  1. Compress representations of the world into something learnable
  2. Reconstruction allows for unsupervised learning (no labels needed)
  3. Reparameterization trick enables end-to-end training through stochastic sampling
  4. Interpret hidden latent variables using latent perturbation
  5. Generate new examples by sampling from the learned latent space

⚡ One-Line Recall

Autoencoder → compress and reconstruct, no labels, deterministic z

VAE → encode as distribution N(μ,σ²), reparameterize, regularize with KL, generate new data

GAN → Generator fools Discriminator, adversarial minimax game, sharper generation
